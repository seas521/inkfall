# INKFALL / 墨坠

一款黑白手绘感的轻量横版动作解谜游戏原型。

这个项目与 `yarn-sprites-demo`、`little-red-dot-game` 完全独立，不复用旧角色、旧场景贴图或团团系统。当前前两关提取并重组了旧原型中已经验证过的 B/C/E 玩法骨架，并以统一的程序绘制方式重新实现。

## 当前流程

```text
悬崖洞口 → 坠入竖井 → 躲避周期火焰下行 → 进入井底根穴
→ 观察三件物品并投掷正确物件堵住出水口 → 穿越尖刺、毒气与移动落脚点
→ 拉动升降梯摇杆进入 1-02
→ 看见对岸木屋与篝火 → 沿左崖斜坡下滑进入风化绳道
→ 在滚石追赶下收卷五段长绳 → 将长绳架到高处锚点 → 沿绳攀爬离开
→ 开启发光宝箱取得盾牌 → 沿左下至右上的长山洞跨越九处断崖
→ 在持续滚落的大小石块间短按 F 盾反 / 长按 F 举盾挡箭
→ 近身挥盾摧毁弩机 → 激活中段检查点 → 抵达对岸木屋
→ 进入 1-03 木屋 → 调查地窖三相结界 → 出门取得斧头并制作火把
→ 点燃壁炉 → 攀上家具拉开窗帘 → 拾回炉边焦木撑开窗扇
→ 炉火、月光与穿堂风闭合结界 → 打开地窖入口并坠入迷雾地窖
→ 探索回路并找到绞车绳索 → 返回西端废井架绳下井
→ 找到十字镐 → 三次凿开井底碎石取得钥匙
→ 沿已理解的矿道徒步抵达监牢并营救老魔法师
```

## 操作

- 启动后使用 `↑ / ↓` 在独立 DEBUG 菜单选择 `1-01` 至 `1-03`、`1-01 C区 · 根穴美术 Demo` 或 `原创场景 · 沉钟雾谷`，按 `Enter / F` 进入
- 也可以在场景根节点 Inspector 的 `DEBUG / Debug Start Level` 中指定启动时直接进入的关卡；选择“运行时关卡菜单”则保留菜单
- `A / D`：移动
- `Space / W`：跳跃
- `F`：第一关用于拾取、放下、投掷和拉动升降梯；第二关绳道用于收绳和架绳；盾行山洞中短按盾反、长按举盾；第三关用于场景交互
- `↑ / ↓`：投掷瞄准
- `R`：重置当前区域
- `Esc`：返回 DEBUG 关卡入口

原型逻辑分辨率保持 1280×720，启动时使用系统最大化窗口并等比例拉伸，不改变同一玩法视野。

项目使用少量分层美术贴图配合 Godot 程序绘制与 shader：机关、水、毒气、火焰和环境微动效仍由运行时代码生成。第二关远景、盾行山洞出口与第三关屋外共用同一个木屋前院绘制函数，只根据观察距离改变缩放，避免同一地点出现不同造型。地窖以固定拓扑、局部光圈和房间地标建立迷路感，不依赖随机地图。

`1-01 C区 · 根穴美术 Demo` 会跳过井口与竖井，直接从井底根穴入口开始。当前 demo 采用黑白“井底黑河”：入口、中段和出口分别使用独立的远景概念美术底板，并在运行时交叉淡化；玩法层保留纯黑剪影，镜头边缘叠加失焦遮挡、暗角与颗粒。瀑布改为低频密度变化的灰白雾化水幕，河流保持近黑，只在瀑布落点和升降梯附近显示宽而低对比的断续反射。

`原创场景 · 沉钟雾谷` 与现有关卡完全独立，只复用角色移动。场景使用带体积受光的远景钟窟、动态黑雾遮罩、中景吊装结构、清晰交互地面和预失焦镜头前景五个深度面，并叠加柔边光束、漂移雾、接触阴影、颗粒与暗角，用多平面摄影方式营造黑白电影的空间感。
