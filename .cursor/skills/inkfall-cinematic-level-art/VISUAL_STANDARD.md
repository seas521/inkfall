# Inkfall 电影化关卡美术标准

这是最低质量线，不是构图模板。后续关卡必须达到此标准，并在主题、色彩、地标或动效上形成自己的辨识度。

## 目标观感

- 仍是横版 2D 操作，但画面应像有镜头、景深、空气和体积的 2.5D 电影场景。
- 黑色不是空白，而是用遮挡、厚度、模糊和负空间建立体积。
- 亮部不是描边，而是存在于空气中的曝光区域。
- 第一眼先读到空间和光，第二眼读到角色和路线，最后才看到细节。

## 视觉优先级

1. 角色与可行走路线清晰。
2. 主光区组织构图和空间。
3. 中景地标建立场景身份。
4. 远景说明尺度与环境。
5. 前景、尘埃和颗粒提供镜头感。

细节不得反过来抢占以上层级。

## 分层标准

### 远景

- 建议视差系数：`0.03–0.10`。
- 使用大轮廓、低对比、低细节、轻模糊。
- 必须有暗到明的宽幅曝光窗口，避免全屏同亮度。
- 远景只负责尺度和气氛，不描绘可交互细节。

### 中景

- 建议视差系数：`0.18–0.40`。
- 放置关卡专属地标、桥架、根系、遗迹、机械或建筑结构。
- 形体需要被雾遮挡一部分；不要完整、清晰地展示所有边缘。
- 亮度高于远景但低于角色附近的局部曝光。
- 避免细线勾勒和重复的小装饰。

### 光与空气

- 位于背景和玩法层之间。
- 体积光使用 shader 的连续衰减、流动噪声、顶部渐入和底部渐隐。
- 雾至少有两个速度层；近层移动略快，远层几乎静止。
- 光和雾允许互相遮挡，形成亮度不均匀的呼吸感。

### 玩家交互层

- 视差系数固定为 `1.0`，视觉位置严格跟随碰撞体。
- 主体颜色保持近黑，推荐明度不超过 `0.02`。
- 边缘只允许黑色柔化，不允许可读的亮色轮廓。
- 地面轮廓应有轻微不规则起伏；悬空台阶可更克制，避免影响落点判断。
- 大地面通过下沉的质量、非规则底部和环境遮挡形成重量。
- 悬空平台通过吊索、支架、腹部厚度或锚点表达结构。
- 接触阴影应宽、软、低透明度，不画窄亮边。

### 角色

- 保持全画面最清晰的轮廓和最稳定的局部对比。
- 出生点、关键跳跃和机关附近应有背景光区帮助角色分离。
- 脚下可有很弱的软接触影，不允许发光描边替代可读性。

### 前景

- 建议视差系数：`1.08–1.20`。
- 使用近黑、失焦的大形体裁切画面边缘。
- 通过遮挡制造镜头在环境内部的感觉。
- 避开角色出生点、关键落点、危险提示和长时间移动路径。
- 暗角和颗粒只能统一画面，不能盖住玩法信息。

## 黑色交互层的“质感”

质感来自形体，不来自画线。

允许：

- 不规则但可预测的外轮廓
- 平台厚度和下腹变化
- 前后遮挡
- 支撑、吊索和锚点
- 黑色柔边
- 宽而弱的接触阴影
- 灯光在平台周围的雾中显影

禁止：

- 白色或灰色顶边
- 沿碰撞面绘制高光
- 均匀裂纹、铆钉、接缝和面板线
- 多条平行渐变带伪造厚度
- 每个平台使用相同的几何装饰
- 以发光轮廓提示可跳跃区域

在缩略图中，平台必须先读作有重量的黑色物体，而不是矩形 UI 或矢量图形。

## 体积光标准

主灯光必须满足：

- 使用独立 CanvasItem shader 或等效连续材质。
- 采用平滑锥形遮罩，不使用硬边多边形。
- 用至少两级缓慢噪声调制密度。
- 光锥顶部自然渐入，接近地面前自然渐隐。
- 内部亮度不均匀，但变化速度不能像水波或屏保。
- 灯具只产生轻微脉冲，避免明显周期闪烁。
- 光源和光锥位置共享同一份配置数据。
- 光锥位于玩法轮廓后方，不把地面染成亮色贴片。

建议起点：

- 体积光强度：`0.22–0.36`
- 灯具呼吸幅度：基准亮度的 `3%–7%`
- 光锥底部渐隐开始：高度的 `78%–86%`
- 地面漫反射软斑透明度：不高于 `0.03`

这些数值用于建立层级，可根据关卡底色微调。

## 色彩标准

- 黑色交互层保持中性，不随背景大面积染色。
- 每个关卡选择一个主环境色和一个受控的强调色。
- 饱和亮色集中在背景曝光、雾、魔法、液体或剧情地标中。
- 不允许全屏均匀铺绿色、紫色、红色或其他单一色罩。
- 色彩丰富来自冷暖、明暗和局部饱和度差异，不来自平均增加颜色数量。
- 即使采用彩色场景，角色路线仍主要依靠明度层级读取。

## 动态标准

### 尘埃

- 必须漂移、旋转或缓慢上升。
- 至少三档深度速度和尺寸。
- 出现与消失使用生命周期包络，不突然闪现。
- 分布不均匀，亮区中更可见。
- 禁止静态、等距、同尺寸白点。

### 雾

- 运动速度低于角色和前景。
- 使用大面积、低透明度形体，不用清晰云朵贴片。
- 黑雾负责遮挡，亮雾负责显示体积，两者都应缓慢变化。

### 前景

- 轻微移动即可；幅度应明显低于游戏物件。
- 吊索、草、悬挂物的相位应错开，避免同步摇摆。

## 构图标准

- 出生点在首帧必须成立：角色、地面、主光和一个场景地标同时可读。
- 每个屏幕宽度至少有一次明暗节奏变化，不允许持续同亮或同黑。
- 主要地标不要正好贴在角色轮廓后面。
- 光区引导路线但不直接画路线。
- 前景遮挡用于建立深度，不用于填补空白。

## Godot 实现约定

- 当前逻辑画布以 `1280 × 720` 为基准。
- 背景和前景长场景可使用至少四张循环 Sprite，随 camera axis 重排。
- 远景、灯光节点设置在玩法控制器之后绘制但位于玩法轮廓后方。
- 前景使用独立高 `z_index`，不要混入玩家绘制函数。
- 所有动态艺术节点统一实现：

```gdscript
func sync(delta: float, camera_axis: float, active: bool) -> void:
	visible = active
	if not active:
		return
	# Update time, parallax, materials, then queue redraw.
```

- 碰撞矩形可用于生成视觉轮廓，但不能因视觉形变改写碰撞。
- 新位图必须确认真实文件格式并通过 Godot 导入，不接受扩展名伪装。
- shader 材质若每盏灯参数不同，必须创建独立 `ShaderMaterial`。
- 删除被 `return` 永久跳过的旧绘制分支，避免后续误改无效代码。

## 常见失败与修正

### 看起来像纸片

检查是否缺少平台下腹、前后遮挡、接触阴影、中景雾遮挡或前景裁切。不要添加白色边线补救。

### 看起来像几何图形

减少规则矩形和均匀采样；增加外轮廓变化、结构支撑和局部遮挡。不要添加裂纹、铆钉或面板纹理补救。

### 灯光像贴图

移除静态光斑和分层多边形；增加连续边缘衰减、低频流动噪声、黑雾遮挡和底部渐隐。

### 画面太平

先检查视差差异和明度层级，再检查模糊与雾。不要先增加细节数量。

### 画面太脏

降低中景细节、尘埃密度和前景覆盖，保留一个主曝光窗口。

### 路线不清

调整角色背后的背景明度和前景遮挡，不给平台加亮边。

## 验收清单

只有全部满足才算达到标准：

- [ ] 远景、中景、玩法层、前景可通过移动速度明显区分。
- [ ] 玩法碰撞和关卡流程未被美术改动。
- [ ] 地面与台阶不存在白色、灰色或彩色顶边。
- [ ] 黑色平台在缩略图中仍有重量和结构，而非简单矩形。
- [ ] 主灯使用动态体积光，边缘没有多边形分层感。
- [ ] 光锥内部有缓慢非均匀变化，并在落地前渐隐。
- [ ] 尘埃持续移动且具有深度差异。
- [ ] 前景建立镜头感但不遮挡关键操作。
- [ ] 角色是最清晰、最易读的元素。
- [ ] 出生首帧具有清楚的角色—光—地标关系。
- [ ] 静态截图有空间层级，连续观察时有空气流动。
- [ ] Godot headless 校验、shader 编译和资源导入均无错误。
