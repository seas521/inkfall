# Inkfall 当前角色与环境融合标准

当前第一章使用帽衫男孩的既有逐帧资源，入口为 `scripts/actors/hood_frame_actor.gd` 与 `hood_actor_manifest.gd`。场景美术或镜头优化不授权更换形象、换成骑士、重画面部、改变体型或重做全部动画。

旧巨盔骑士、独立 SVG 帧等要求仅属于 [历史角色实验归档](references/legacy-character-prototype.md)，仅在用户明确要求维护该实验时读取。共通语义与连续性原则可复用，具体渲染方式以当前资源为准。

## 造型、尺度与受光

- 保持当前角色体型、脸部与眼睛设计，不新增五官，不裁掉脸部、头部或手脚来解决物体遮挡。
- 静止时体型和轮廓稳定，取消呼吸引起的缩放、忽大忽小与周期性鼓动。
- 所有动作共用固定显示尺度、根节点和脚底基准。禁止按逐帧/逐片段包围盒重新居中或缩放，禁止用伸长肢体迁就接触。
- 动作切换、爬上梯子站稳、进出矿车、搬物起身均不能突然增高、缩小或跳位。
- 角色以近黑为基底，但允许环境光在迎光面产生克制的局部变化。光源、方向、时序与周边道具一致，背光侧保留深暗；不能永远死黑，也不整体刷灰或全身白边。
- 角色脚与当前地面、台阶/车/平台的接触必须可辨，焦点和光效不能掩盖悬空或穿插。

## 语义与物理分工

场景控制器维护物理、命中、物体与地形位置，角色系统只读取姿态。按实际接口传递脚点、速度、朝向、着地状态、装备、动作阶段、力度与受光等语义，不能让动画切换重置物理位置。

失败/重击优先于交互，交互优先于普通移动，但中断、松手和跳跃应依照当前控制器已有约定处理。不要为视觉平滑新增强制自动行走、隔空吸附或不可取消的长动画。

## 交互必须有接触和重量

- 推：双手实际撑住物体，身体前压，后脚蹬地，短步循环随真实位移推进。
- 拉：面向物体抓稳把手，身体后仰，重心与后退步协调；不能倒放推车片段代替全部拉车。
- 正反切换、停止、物体受阻、松手与跳跃中断要连续。物体没动时不能继续快速踏步，物体移动时不能用静止人物平移。
- 大物体贴胸抱在怀里；拾取先蹲身、手臂接触，再起身后仰承重。不能悬空托举、物体飞来、人物脸变形或透明贴层切脸。
- 投掷由当前站位、朝向、出手点和速度决定。若用户未要求自动对位，不先走到预设点，不固定落到篮子某一侧。
- 入篮表现为物体轨迹穿过开口，被前沿遮挡，落到底部并引起偏载/晃动；取出先接触再抬升，不能瞬移到怀里。
- 爬梯子先接触梯子，手脚沿踏棍交替承重；不第一脚踩空气，不左右漂移。完成后与普通站姿的尺寸、位置和形态连续。
- 上下台阶要按真实踏步距离同步脚步；保留合理移动速度，不用频繁上下抖动代替步态。
- 角色跌落、被砸倒、抵抗矿车应有不同受力过程；不能用过快的多个动作硬切制造抽搐。

## Seedance 通用动作素材

先检查现有素材与控制器能否满足需求。需要重做时，提示词围绕动作而非某块特定石头；通用抱大型物体优先明确无实物表演和怀抱空间，不能默认为所有未来物体都画一块石头。若为改善动作必须提供辅助道具，由当前用户需求决定其颜色、抠图方案与是否保留。

完整描述应交代固定镜头、角色朝向与造型、画面尺度、背景、时间轴、真实发力、触点、步态、动作起止及可循环区间。严格区分背身爬梯与正侧身动作，不能生成后再靠扭曲身体迁就梯子。

### 连续抽帧规则

- 新 Seedance 视频沿用项目既有 `24 fps` 连续抽帧候选流程；这是素材处理约定，不是游戏渲染帧率。已有清单中的 60 fps 资源不因此重新采样。
- 可先稀疏总览定位起止，但接入、质量、循环点与衔接必须复核动作区间的全部连续帧，不能拿稀疏关键帧直接播放。
- 只能删除动作开始前与结束后的连续无关区间；不要删内部过渡帧。调整速度优先改播放时长并同步物理接触时刻。
- 同源片段共用固定缩放、水平根节点和地面基线；禁止每段按自身包围盒重新缩放或逐帧居中。
- 循环要确认实际步态周期数，以真实位移推进；不能靠加速到抽搐掩盖脚滑。
- 接入前看连续动态预览，检查造型、眼睛、边缘、残影、装备和衔接；再逐帧查画布边界，有效像素留至少 3 px 安全边距，源图裁断不能靠把残缺帧往里挪来修复。

## 验收

同一段连续操作覆盖：待机→接触→发力/搬运→停止→反向→松手/落地→待机，以及允许的跳跃中断。既查原生帧，也查真实按键响应。

- 角色比例、脚点、根节点不跳变；空闲不呼吸缩放。
- 手脚接触成立，物体与身体不出现白缝、透明切层和形变。
- 搬运、推拉、攀爬速度与步态协调，不滑行、抽搐、吸回物体或自动走到预设投掷点。
- 暗区与亮区中角色均可读，受光侧随光源/朝向正确变化；人物与周边物件风格一致。
- 原有物理、输入、检查点与已批准动作资源不因美术任务被替换。
