# 《墨坠 / INKFALL》游戏总纲

## 游戏定位

轻量级横版动作解谜游戏。玩家控制一名仅由黑白线条构成的小魔女，在失去颜色的世界中探索井穴、断层和废弃设施。

游戏不依赖大量场景贴图，而依靠清楚的空间轮廓、物理互动和少量高辨识度色彩建立记忆点。

## 核心体验

- **观察空间**：先判断安全落点、机关位置和危险节奏。
- **利用物件**：场景中明确标记为可拾取的物件都能拿起、放下和投掷。
- **改变环境**：物件不是钥匙图标，而是直接参与物理问题，例如堵水、压住机关或隔绝喷口。
- **动作执行**：解法被理解后，仍需通过跳跃、落点控制和投掷完成。
- **输入分化**：同一按键会形成清楚且互斥的短按/长按动作，例如短按盾反击碎滚石、长按举盾抵挡连续飞箭。
- **物件再解释**：已经完成一次用途的物件仍可能留下可观察的实体，例如点炉后的焦木先掉在壁炉旁，玩家必须重新拾取，才能发现它还可以撑开窗扇。

## 美术规则

- 世界主体使用黑、白和两档灰色。
- 角色、平台、墙体和机关使用清晰黑色外轮廓。
- 不使用写实纹理、AI 背景图或复杂装饰。
- 颜色只承担玩法信息：水为青蓝色、毒气为绿色、火焰为橙色，可收集绳索为麻绳棕色，盾牌成功反馈为金色；普通平台与装饰不额外增加颜色。
- 静态环境和动态机关都使用同一套线宽与形状语言，避免贴图拼接感。

## 公共交互规则

- 可拾取物统一带有小型双线轮廓，不用文字说明物品类别。
- 任意标记物都能拾取和投掷，但机关只接受尺寸、形状或重量合适的物件；错误物件必须给出清楚的物理排斥反馈，并允许再次拾取。
- 轻按 `F` 放下携带物，长按 `F` 后松开投掷。
- 投掷轨迹由细线与间隔圆点显示；轨迹只在蓄力时出现，并与真实投掷使用完全相同的角度、力度、重力和命中区域。
- 失败仅回到当前区域检查点，方便原型阶段反复验证。
- 长型材料不使用瞬间进入背包的抽象反馈：拾取绳索时，场景中剩余绳段会缩短，角色手边的绳圈会逐段增大。
- 取得盾牌后，`F` 的语义切换为“短按盾反 / 长按举盾”：盾反处理瞬时滚石，举盾处理持续飞箭，两者不能互相替代。
- 所有依赖重力的追逐路线必须与空间坡势一致：山洞整体从左下向右上延伸，滚石从统一的右上源头持续落下，再跨越断口逐级向左下滚落。
- DEBUG 同时提供运行时关卡菜单和 Inspector 默认启动关卡选项，方便跳过前置流程单独验收。
- 同一地点在不同关卡中的远景、出口和可探索场景必须调用共享轮廓，不允许复制后各自修改造成空间断裂。

## 当前开发范围

目前制作第一章前三关：`1-01` 验证竖向动作与通用投掷物谜题；`1-02` 验证滚石压力、连续收集反馈、“材料直接变成移动路径”以及盾牌短按/长按分化；`1-03` 从木屋解封连续进入根下旧矿，验证跨房间物件链、环境条件结界、物件二次利用、固定拓扑迷宫与路线记忆，并以营救老魔法师作为当前版本终点。
