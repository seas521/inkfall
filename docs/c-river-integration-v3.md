# C 区连续河流与材质统一 v3

## 截图反馈对应修改

上版 river world rectangle 仍为 x=560..2950，shader 又在该范围作岸边淡出，导致起始平台下没有连续河流。此版绘制范围改为 x=-320..3780、y=605 起，覆盖 C 区镜头 x=0..3340 全程。原先 y=605 的河面高度不改，不增加游泳或水体碰撞。

河流效果节点位于主绘制之上，因此专门以起始台实际石材贴图 alpha 遮罩水体，保持平台前、水体后的遮挡，避免河水染到台阶正面。横向波纹使用世界坐标，滚屏不会重新定位波纹。

参考用户提供的《奥日》截图，采用局部冷青水光、落点水雾、低位向外涟漪；不复制原画、布局或整屏高饱和配色。

出水口石环、喷气口底座、尖刺表面及底槽通过运行时多边形纹理映射，复用 `rock-platform.png` 中的手绘石材片段，替代先前纯色几何面。保留现有圆孔投掷目标和所有危险范围，毒雾本身仍使用 v2 动态体积材质。

## 验证与限制

GDScript 静态解析通过；修改函数范围只涉及绘制与效果同步，玩法常量/伤害/移动逻辑未改。未启动 Godot；未进行 shader 编译、性能和实际画面验收。

此版先验收整段河流连续性、起始台水体遮挡、石材与机关轮廓。不宣称达到参考游戏的最终美术质量。

`backups/c-river-v3/` 保存本次之前的 main、env_fx 和 water shader，可回退。
