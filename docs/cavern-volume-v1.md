# B/C 实时体积与受光试作

## 实现
- `inkfall_volume.gdshader`：沿虚拟深度轴采样 20 步三维动态密度，前后积分透明度。火焰使用热度分色，毒雾使用偏移密度近似内部遮光。不使用静态火焰贴图或 Blender 固体焰舌。
- `inkfall_water.gdshader`：连续时间驱动波面法线与定向高光；河面使用纵向压缩的波纹坐标表现景深，世界横坐标保持滚屏一致。瀑布增加明暗流束、落水泡沫；主脚本绘制飞沫与口部水帘衔接。
- 出水口：凹喉、分块倒角石环和接触阴影；喷气口为有明暗面的金属槽。C 区台面下缘增加水色反光近似。
- B 井口光柱固定在世界 y=0，向下展宽和衰减。170 个分布于整口井的尘点按世界深度裁剪，在光束内更明显。
- `inkfall_exposure.gdshader`：B 区环境乘色暗部与最多 8 处局部火光；火光跟随既有火势强度。保留井口冷光与 HUD 上下区域，不改变角色星光。
- 新效果节点池在每帧开始隐藏，按当前场景复用；离屏气柱不绘制，河面裁剪至屏幕。

## 边界
这是 2D Canvas 上的体积采样和光照近似，不是 Navier–Stokes 流体模拟，也不是完整 3D 场景。没有几何投射阴影、真实反射或屏幕折射。B 区乘色曝光作用于环境，角色另层保持可读性。C 区目前没有火焰伤害机关，仍保留尖刺，不擅自改变机关类型。

## 验证
未启动 Godot。静态 GDScript 解析、资源路径、修改函数范围检查；shader 尚未由 Godot 编译，不能宣称已完成视觉或性能验收。

试玩检查：进井光柱是否固定、深处台阶可读性、熄火时明暗是否平顺、受击与火势一致；C 区水帘关闭后是否残留、气体开关和范围、河面滚屏是否稳定、菜单/重生/电梯切换无效果残留。若需回退，`backups/cavern-volume-v1/main.before` 保存本次之前的主脚本；新增效果脚本和 shader 保留为未引用资产即可。
