# B/C 轮廓与融合调整 v2

依据实际截图：放弃强烈 3D/塑料高光，以横版可读性和背景融合优先。

- 河流：灰蓝低饱和，横向断续波纹，世界坐标固定纹理相位；上下与真实河流左右端不规则/渐隐，去掉竖向亮条。
- 瀑布：口部较窄、下落展开，噪声软边、降低白亮条，末端淡化。飞沫位置由水帘矩形底部 y=640 调整到河面 y=605；碰撞矩形不变。
- 出水口：移除方形砖块底板，改不规则暗石轮廓，保留可识别的圆孔目标与石环。
- 毒雾：三维重叠雾团随时间上升，减少阈值造成的绿色细线，移除中心增亮，颜色降为灰橄榄绿。
- 尖刺：保留收缩与伤害范围，改为收腰齿形、双面明暗和底槽，不再是纯红三角片。
- 火焰：保留原体积积分/热度分色；移除宽圆锥包络，用四条不同高度和相位的弯曲窄焰舌。

没有启动 Godot。GDScript 静态解析通过，不等于 shader 编译、性能或画面验收。此版需要以实际截图再验收，不追加装饰。
