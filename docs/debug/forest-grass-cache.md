# 森林草皮延迟出现 / 重复生成优化

2026-11-10。保留并暂停双路吊运站制作，本次只修改森林草皮。

## 发现与修改

贴图 `forest_grass_strip.jpg` 已经通过 preload 载入；原逻辑仍在每个渲染帧按当前镜头范围重新采样地形、筛选草皮位置、建立随机数生成器和生成草簇/草根带的绘图命令。

改为在第一次显示时为整个森林范围建立固定的世界坐标绘图命令，随后只改变两个草皮节点的位置以跟随镜头。没有按玩家位置载入或显示新区块的逻辑。贴图、随机种子、草簇密度、坑洞/水塘/倒木避让保持原值。

追猎破坏悬崖会改变有效地面边界，因此该边界变化时仍刷新两层草皮；回到原场景时按边界重新校验。

## 验证

原生 Metal 下，相同 180 次镜头滚动前后对照：

- 修改前：草簇 180 次生成 / 33.198 ms 总 CPU，草根带 180 次 / 97.595 ms；合计约 0.73 ms/帧，仅为草皮命令生成时间。
- 修改后：进入场景的绘图已准备完成，镜头滚动期间两层均为 0 次重新生成。
- 覆盖新区域、返回旧区域和悬崖边界破坏刷新。
- 比对出生附近、倒木和尖刺坑附近原生截图，保留草皮形状与地表遮挡。
- `scene1_smoke.gd`：起身、地形障碍、乌鸦、自动行走及进入断木桥流程通过。

专项工具：`scripts/demos/c_zone_debug/forest_grass_capture.gd -- --after`。对照截图：`artifacts/forest-grass/`。

这证明消除了草皮的逐帧生成和镜头范围生成逻辑，不代表整场景总帧耗时减少 0.73 ms；其余背景、角色、特效仍有独立开销。


## 2026-11-11 · 坑边与陡坡草皮贴合修复

矩形草片原先只检查中心点是否可种草，绕中心旋转到坡面后，宽草片的土块底部会伸出弯曲地表，甚至跨到尖刺坑上方。

现在沿每块草片的完整宽度采样真实地表，生成贴合曲面的带状轮廓；每个小区间检查有效地面，遇到坑、水和倒木时终止。源贴图只采样草叶及2px埋入地面的根部，不再把大块矩形土底画到场景中。随机草种、翻转、密度和世界位置仍固定；碰撞、尖刺坑与食人花玩法未变。

整个森林仍预先生成绘图并复用缓存。`forest_grass_surface_capture.gd` 覆盖尖刺坑口、食人花坡面、水潭岸边和上坡；`-- --play` 从尖刺坑前试玩。原生截图：`artifacts/forest-grass/surface-fix/`。

森林与食人花流程分别由 `scene1_smoke.gd`、`forest_predator_smoke.gd` 检查；镜头滚动、返回旧区域和破坏边界的缓存检查沿用 `forest_grass_capture.gd -- --after`。

水潭边缘另外使用缓存的地面边界距离场：岸边24px内逐渐降低草高、密度与透明度，草根带同步收拢，不再把一簇完整高度的草从中间竖直截断。距离场随地形边界一起更新，镜头移动不重建。`forest_grass_surface_capture.gd -- --play --pond` 可直接检查水潭岸边。
