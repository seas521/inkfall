# C 区推拉：Seedance 补充动作

## 当前试接状态

2026-10-12：已将用户提供的 8441 推拉视频连续抽帧接入独立 C 区 debug。当前先实机体验，不需要立即再消耗 Seedance 额度。配置与已知限制见 [C 区场景说明](c-zone-river.md#美术与动作)。预览与抽帧审计仍保存在 `artifacts/seedance-push-pull-8441/`，游戏使用独立的运行时 PNG 副本。

以下为后续补片的动作内容清单，不是 Seedance 时长选项；实际只选 5 秒或 10 秒。

## 后续补片内容

| 动作 | 建议视频时长 | 动作要求 |
| --- | --- | --- |
| 伸手抓握 | 2 秒 | 待机后伸出双手，接触身前箱体侧面木条，最后保持。没有把手。有效动作约 0.4–0.6 秒。 |
| 抓握待机 | 2–3 秒 | 双手固定，脚底不动，轻微呼吸和负重，不变成普通待机。 |
| 倒退拉箱循环 | 4 秒，优先 | 始终朝右，双手伸在身体右前方，重心向左后方倾；双脚交替短步后退，不转身，不正向跑步。至少两个完整循环。 |
| 前进推箱循环 | 4 秒 | 始终朝右，身体前倾，后脚蹬地、前脚短步，双手接触点稳定。至少两个完整循环。 |
| 松手恢复 | 2 秒 | 从同一抓握姿态放开双手，收臂、重心回正，恢复待机。有效动作约 0.3–0.5 秒。 |

优先做「倒退拉箱循环」，先验证造型、步态、手点，再批量做其余动作。左右方向共用整帧镜像，不需要再生成朝左版本。

## 共用拍摄要求

使用当前 Seedance 骑士原参考图，不使用游戏里临时 SVG 占位造型。固定正侧面镜头，角色始终朝右，全身入画，保留至少 10% 画面边距。镜头不可移动、缩放或旋转，保持同一体型、头盔、眼睛、角色比例、水平根节点和地面基线。不要让角色在画面中横向漂移。

使用均匀纯色绿幕，无渐变、阴影、地面纹理、字幕、拖影或运动模糊。只生成角色，不烘焙箱子或场景，不生成把手；双手做直接接触箱体侧面木条的姿态，推时撑住、拉时抓住木条边缘。短手臂双手伸向身前，手点约在总身高下方三分之一处，保持手部稳定，不随着步伐大幅摆动。推拉片段用原地步态表达运动，最终位移由游戏物理控制。

## 倒退拉箱提示词

> 严格使用参考图中的同一黑色巨盔小骑士，保持头身比例、头盔轮廓和唯一眼睛一致。固定正侧面镜头，全身完整入画，角色始终面向右侧。角色双手做直接抓住右前方箱体侧面木条边缘的姿态，没有把手，箱子本身不出现在画面中。双臂稳定伸向前方，重心略向左后方倾斜，双脚交替小步向后拖拽重物。面向右侧但向左后退，不转身，不做向前跑步。原地循环步态，角色不在画面中横向漂移，双手接触位置稳定，动作有重量但连续自然。至少两个完整步态循环。均匀纯绿背景，无箱子、把手、场景、地面阴影、文字和运动模糊。机位、缩放、角色大小及脚底基线全程固定，头盔和脚部远离画面边缘。

## 收到视频后的处理

- 按 24 fps 连续抽取全部有效帧，不隔帧，不删除动作内部过渡帧。
- 只裁剪片头片尾的连续无关区间；同组动作保持固定缩放、根节点和脚底基线，不逐帧重心对齐。
- 抠图后检查每帧四边至少 3 px 安全边距，并检查头盔形状、眼睛数量、手点、绿边和残影。
- 生成全部连续帧的动态预览，确定循环起止与实际步态周期数，再按真实位移调节播放。
- 只替换 C 区本地动作适配层，先验收抓住、停步、反向、松手、跳跃中断，再决定是否推广到其他关卡。
