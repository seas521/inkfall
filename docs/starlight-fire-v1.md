- 第一关角色：炭黑衣帽、银灰发丝、折尖星饰帽。12 帧源图，前两行移动/跳跃/持物，末行受击死亡。
- 单独的加色星光与柔光，保留已有地面接触阴影。死亡优先于所有移动和持物帧，最后淡出并沿用原重生逻辑。
- B 区火焰：连续时间驱动的多层摆动焰舌与上升火星；原危险矩形、启停周期、跳跃和检查点没有修改。
- 灼伤反馈：短促接触闪光、抛物线火星、烟灰，删除红圈与灼伤文字。沿用已有失衡运动，不更改死亡时长。

## 资源与生成记录

使用内置 imagegen。动作源图 `assets/art/level01/witch-starlight-key-v1.png` 是 RGB 绿幕图，**不是透明 PNG**。`inkfall_actor_art.gd` 独立 ShaderMaterial 按绿色优势去底并压制绿边；不能脱离该材质直接作为普通透明贴图使用。

生成提示核心：保留原魔女脸形与手绘风格；炭黑石墨色衣服，银灰轮廓光，折尖帽和四角星饰；4×3 的十二动作，最后四帧是闭眼受击、蜷缩、失力侧落、无意识坠落；不烘焙光晕。第二次仅将棋盘底替换为纯绿色供运行时抠像。

旧白衣动作资产与 Blender 火焰源文件均保留。新动作仍是逐帧 2D 手绘，不是 Blender 骨骼模型。持物目前共用一帧持石姿态，后续可细化不同物品的手部动作。

## 验证边界

未启动 Godot。gdtoolkit 语法解析通过；12 个裁剪区域边界均无角色像素被截断；源图背景满足抠像阈值。此检查不等于 Godot 着色器编译或视觉验收。

试玩重点：站立/左右跑动的脚底稳定性；黑衣背景辨识度；星芒是否过亮；火焰开关与危险范围；手持物受击仍优先死亡动作；重生后恢复正常透明度。
