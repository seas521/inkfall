# 1-02《风化绳崖》关卡设计卡

## 关卡目标

从升降梯抵达左侧悬崖，沿斜坡进入下层绳道。在滚石追赶中收起散落的一整条长绳，把绳索架到高处锚点；随后进入盾行山洞，取得盾牌并在持续上行的断崖路线中交替使用跳跃、盾反和举盾，最终抵达开场看见的对岸木屋。

## 空间结构

### A：双崖上层

- 玩家从左侧升降梯抵达。画面右侧隔着无法直接跨越的大型悬崖，远端有一间小木屋和一簇橙色篝火，作为明确的远期方向标。
- 左侧地面向右下方形成不可逆的长斜坡。角色踏上后进入短暂滑行动画，离开上层画面并切入 E 区。
- 木屋与篝火只承担远景目标，不在本次灰盒中提供可直接跳达的平台。

### E：风化绳道

- 绳道由八块固定落脚面和一块横向移动落脚面组成；下方为深坑，不能在地面安全行走。中段两块固定台缩窄至约 42px，仅约为角色宽度的 1.6 倍；另有 48px 和 68px 的短台，只有起点、最后起跳台与终点保留功能性宽度。
- 横向移动台位于第四、第五个固定台之间，宽 48px，在约 130px 的范围内往复，完整周期约 4.3 秒。它靠左时容易从前一台落上，但难以跳到右侧短台；靠右时下一跳明显缩短，因此玩家需要观察起跳时机，但不必在窄台上长时间等待。
- 五个绳结沿移动路线依次分布。第二、第四个绳结悬挂在完整跳跃弧线的最高点附近；只有角色仍在空中且纵向速度接近零时按 `F` 才能收取，提前按键会提示“要在跳跃最高点收绳”。最高点绳结的纵向要求不变，但横向拾取范围扩大到绳结左右约 60px，允许玩家从两侧形成自然跳跃弧线，不再要求正中对齐。当角色进入实际可拾取时机，当前绳结出现麻绳暖色脉冲光环和八向短光芒；场景交互提示只显示 `F`，不再追加“收绳”文字。光效与真实判定完全一致。其余绳结用于调节节奏。
- 五个绳结属于同一条连续长绳。玩家不能隔空或乱序收取，只能按路径顺序靠近并按 `F` 收绳。
- 玩家落入 E 区时，滚石已经停在起始平台、紧贴玩家背后的位置，使用不规则岩石轮廓、灰色岩面和裂纹表现，不再是规则同心圆。玩家越过首段触发线后，滚石先原地震动预警，随后沿绳道追赶。滚石以 135px/s 起步，按 12px/s² 持续加速，最高达到 265px/s；旋转速度与线速度同步。滚石最终会跌入终点前的断口，但在此之前碰到玩家会使本次 E 区尝试失败。
- 滚石使用世界层镜头震动：预警时轻震，滚动时根据速度、玩家距离和不规则石面触地节奏逐渐增强，落入终点断口时达到最大幅度。HUD 不参与震动，避免操作提示和绳索数量难以阅读。
- 倒数第二个平台与终点高台之间保留约 90px 水平缺口和 95px 高差。玩家可以从台面原地起步，长按跳跃完成一次完整大跳直接登上高台；不再要求提前加速，也不再绘制助跑箭头。短按跳跃仍无法达到所需高度。
- 终点右侧设置高处锚点。收齐五段前按 `F` 只提示“绳子还不够长”；收齐后按 `F` 将绳头抛向锚点并自动进入攀爬表现。

### F：盾行山洞

- 沿绳攀到高处后切入山洞入口。入口平台放置一个金色微光宝箱；玩家必须靠近并按 `F` 开启，盾牌以短弧线飞向角色，随后记录本段检查点。
- 山洞主路线固定为**左下到右上**，总长度约 4700px：十段地面从 `y=590` 逐级抬升至 `y=195`，共九处断口。角色始终向右上方前进，最终从最高处洞口回到开场远望的木屋与篝火。
- 滚石不再由玩家踏入某块台阶临时生成。路线最右上方设置统一落石源，在取得盾牌后按独立计时持续落下大小不同的石块；生成间隔从约 2.35 秒缓慢收紧，但不会低于 1.55 秒。
- 滚石先从洞顶坠落到最高路面，落地时扬起与体积相称的尘土并产生距离衰减的镜头震动；随后按恒定加速度向左下滚，转速与线速度同步。滚石越过断口时进入真实下坠状态，落到下一段较低路面再次扬尘并继续滚动，能够沿九个断口贯穿整条上行路线。
- 小滚石半径约 22px，可跳过，也可短按 `F` 盾反击碎；大滚石半径约 64px，高度超过角色完整跳跃高度，必须盾反击碎，不能靠跳跃走捷径。
- 九个断口上方分别设置落石预警：碎屑与橙色圆环先出现，随后石块垂直砸落。头顶落石不能盾反，玩家必须判断时机跨过断口。
- 中段第四平台是一条长按教学走廊。右侧弩机持续向左平射，箭矢高度与角色身体重叠；玩家需要长按 `F` 超过 0.20 秒保持举盾并向右推进。短按盾反不能代替持续防御。接近弩机后可松开防御，再短按 `F` 挥盾将其击毁，弩机停止生成新箭矢并留下破碎轮廓。
- 弩机后方的第一块高台设置山洞中段检查点。玩家落稳后自动记录并显示明确提示；此后失败从该高台恢复，保留盾牌与“弩机段已通过”状态，同时跳过检查点以前的头顶落石触发。持续滚石源会重新计时，避免复活瞬间被旧滚石夹击。
- 长按举盾只对箭矢有效，无法阻挡滚石；滚石撞上举盾中的角色仍会失败。机关不会在举盾走廊上同时生成滚石，避免两条互斥规则造成无解。
- 短按判定发生在 `F` 松开时，并产生约 0.20 秒盾反窗口；成功时出现明显金色弧光、碎石和轻微镜头震动。长按达到阈值后直接转为持续举盾，松开不会补发盾反。
- 山洞出口在最高处。玩家越过出口线后进入木屋外缘，篝火与开场远景形成空间闭环，并显示第二关完成。

## 长绳视觉闭环

```text
看见跨越多个落脚面的连续长绳
→ 靠近当前绳结按 F
→ 麻绳棕色的该段绳索用约 0.48 秒向角色手边收拢
→ 场景中未收取的长绳从起点缩短一段
→ 角色手边的绳圈增加一圈，HUD 的“长绳 x / 5”同步增长
→ 收齐后在锚点处架绳
→ 手中绳圈消失，竖直攀爬绳出现
→ 角色沿绳向上攀爬，完成关卡
```

这种反馈不把绳索处理成普通背包数字：玩家应同时从世界、角色手部和 HUD 三处确认“外面的绳子正在变短，手里的绳子正在变多”。

## 失败与重置

- 被滚石追上或坠入深坑时，先播放冲击/坠落反馈，再回到 E 区入口。
- 当前原型失败后重置五段绳索与滚石，便于重复验证完整节奏。
- `R` 重置当前区域；`Esc` 返回分关卡 DEBUG 菜单。

## 静态与动态资源

### 静态

- 双崖轮廓、远端木屋、锚点支架
- 风化绳道的固定落脚面与滚石导向槽
- 山洞十段逐级上抬的地面、九处断口、宝箱底座、弩机、中段检查点、最高处落石槽和出口轮廓

### 动态

- 篝火
- 下滑入场与 E 区坠落入场
- 48px 横向移动落脚面、导轨与吊索
- 五段可收卷长绳、绳结、角色手持绳圈
- 预警震动、滚石滚动和落崖
- 随滚石速度、距离和落崖状态变化的世界层镜头震动
- 架绳与角色自动攀爬
- 宝箱金色脉冲、盾牌飞向角色、屏幕中央双操作说明、短按盾反弧光与碎石
- 统一源头持续落下的大小滚石、每次落地尘土、断口头顶落石预警、横向飞箭、举盾格挡火花和弩机破坏效果

所有元素继续使用黑白灰程序绘制；橙色用于篝火、升降梯摇杆端点和危险预警，长绳、绳结、手中绳圈与最终攀爬绳使用统一的麻绳棕色。灰色滚石轨道不使用麻绳色，确保两套线路不会混淆。
