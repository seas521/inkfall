# 1-03《月炉木屋与根下旧矿》关卡设计卡

## 关卡目标

玩家进入第二关一直能够看见的对岸木屋。地窖下方传来周期性的 `Help…`，但入口被火焰、月光与风三相结界锁住。玩家需要在木屋内外建立真实的环境条件，而不是把三件钥匙放进三个槽位。

## 空间连续性

- 第二关双崖远景、盾行山洞出口和第三关屋外调用同一个木屋前院绘制函数。
- 木屋的屋顶、烟囱、月窗、门、枯树、斧头位置和篝火相对关系保持一致，只根据镜头距离整体缩放。
- 第三关由屋内与屋外两个相邻房间组成，穿门切换时保留所有谜题状态。

## 空间布局

- 屋内不再是一条空走廊，而是依次形成玄关、壁炉起居区、楼梯、阁楼月窗和后部储藏地窖五个可辨认区域。
- 餐桌、杯具、地毯、壁架、罐子、挂草、画框、床铺、书册、储物柜和麻袋构成生活痕迹及视觉干扰，但不会伪装成可交互物。
- 楼梯和阁楼不仅是装饰，绘制位置与碰撞台阶一致；玩家需要实际向上走到月窗，而不是在平层里完成全部谜题。
- 屋外分为树下前院、篝火区、木屋主体和屋后工具区。斧头放在木屋后侧的柴堆、围栏及农具之间，不再直接陈列在树前。

## 解谜流程

1. 玩家出生在木屋内，远端地窖以文字和扩散波纹周期传出求救声。靠近按 `F` 后，屏幕中央显示黑白线条构成的三相结界；未完成节点保持空白。
2. 玩家出门，在枯树旁拾取斧头。对树干连续挥砍三次后，树枝掉落，斧头卡在树干里，避免引入额外的丢弃按键。
3. 拾取树枝，在屋外篝火前按 `F` 挥动并点燃，得到火把。
4. 把火把带回屋内点燃壁炉，火焰节点填入橙红色。火把不会继续自动拿在手里：它熄灭成焦木并落在壁炉侧边，看起来像已经完成使命的废料。
5. 玩家利用桌、柜和横梁爬到高窗，拉开窗帘。月光照入屋内，月光节点填入冷白色；窗扇尝试开启后会自行合拢。
6. 玩家必须回到壁炉旁重新拾取焦木，再带到高窗，用焦木撑住窗扇。炉火产生的热流与打开的高窗形成穿堂风，窗帘与风线开始移动，风节点填入低饱和青色。
7. 三相闭合后，结界自动显示完成状态。玩家回到地窖入口按 `F` 打开木门，再主动落入入口，进入地窖迷宫衔接画面。

## 信息与反馈

- `Help…` 不是常驻 HUD，只从地窖位置周期出现，并附带扩散声波，明确声音来自地下。
- 每完成一个条件，地窖印记短暂闪亮；中央结界图中的对应实体由黑白变为功能色。
- 所有普通交互都只显示无文字说明的圆形 `F` 提示，不再直接写出“拾取、砍树、点燃、拉开”等答案。
- 焦木出现时不弹出“下一步使用它”的说明，只保留世界中的实体；玩家需要主动回到壁炉旁观察并再次拾取。
- 火焰用橙红色、月光用冷白色、风用低饱和青色；不使用紫色。

## 地窖衔接

- 跳入地窖后先播放纵向坠落镜头，再以短暂黑场进入迷雾地窖中央厅；不是直接瞬移到可操作状态。
- 地窖是同一张连续地图，通过房间边缘的门洞、梯口和狭道连接；每次跨房间使用极短遮罩过渡，不改变迷宫状态。
- 地窖作为本关下半段连续进入，完整设计、机关闭环与检查点见 [地窖段设计卡](level-03-cellar-maze.md)，不再提供独立的 `1-03B` 测试入口。

`R` 会从木屋起点重新开始整个 `1-03`，`Esc` 返回 DEBUG 菜单。
