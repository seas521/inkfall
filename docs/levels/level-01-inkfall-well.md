# 1-01《墨坠井》关卡设计卡

## 关卡目标

从悬崖边的井口进入地下，穿过竖井与井底根穴，恢复最右侧升降梯并前往下一关。

## 空间结构

### A：悬崖井口

- 单屏横向空间，左侧为出生点，右侧为突出的天然洞口。
- 洞口没有井盖。玩家主动跳入后进入一段不可操作的短暂坠落表现。
- 地表火焰使用橙色，是开场唯一颜色焦点；洞口保持纯黑。

### B：雨根竖井

- 独立的纵向空间，角色先落到井顶的单个窄缓台。
- 井筒有效内宽约 240px，落脚点宽约 90px，仍保持约为角色碰撞宽度3.5倍的旧版平台比例。
- 后续落脚点在井筒内左右交错悬空，每块台阶距最近井壁约32px。空隙略大于角色26px碰撞宽度，因此靠墙端也可能踩空，井壁不再充当安全护栏。
- 原静态尖刺改为橙色周期火焰，依次经历熄灭、微光预警、喷发和回落；只有喷发阶段造成伤害。
- 每段火焰占据靠近井心的约62px，只在外侧保留约28px、即一个角色宽度的安全唇边。该唇边本身仍与井壁隔着空隙；玩家落得过外会坠落，落得过内会撞上喷发中的火焰。
- 相邻落点的自然下坠速度低于 920；漏掉一层或尝试跳跃越级会超过 920，立即回到最近检查点。因此路线允许逐层下落，但不能从第一层直接落到第三层。
- 安全端与危险端通过纯白踏面和橙色火焰直接区分；入口缓台是唯一完全无火焰的平台。
- 玩家可以不借助特殊伙伴完成全部下降路线。
- 接触喷发火焰时先出现橙色冲击环、火星和“灼伤·失衡”反馈；角色锁定输入、短暂反弹后坠落，约0.8秒后才回到检查点，不瞬间传送。
- 漏掉台阶触发高速坠落时也会先保留一段可见的下坠画面，再回到最近的竖井检查点。

### C：井底根穴

- 横向展开的悬崖水穴，底部不能直接行走。
- C 区横向长度约 3300px；由 14 个固定落脚面、3 个往复移动落脚点和 1 个斜向索道车组成，明显长于初版。
- 起点放置石块、短木和金属残片；它们都使用同一套拾取与投掷规则，但不是等价答案。
- 上方出水口形成宽而连续的青蓝水幕，水幕会把玩家推回。
- 出水口保留圆形内轮廓作为观察线索：只有外形与重量都合适的石块能够卡紧。短木和金属残片命中时会被水流弹开，播放青蓝冲击环、飞溅、水流叉号和“卡不住”的短反馈，随后落回并可再次拾取。
- 投掷轨迹按与真实投掷相同的重力、力度与角度进行 60Hz 密集采样，并完整显示到落地或真实命中点；命中可见开口时终点出现青蓝圆环。长按增加力度，按 `↑` 抬高轨迹。
- 出水口命中区严格收在可见圆形插槽内部，不允许抛物线从插槽下方擦过却被判成功。
- 堵水后移动落脚点开始工作。后半程交替设置 5 组周期伸缩尖刺与 8 处间歇毒气，不再是单一毒气走廊。
- 接触尖刺或毒气都不会瞬间复位：角色先受冲击失衡并坠落约 0.76 秒，再回到检查点。毒气使用绿色雾团、脉冲轮廓与“中毒·失衡”提示，尖刺使用黑色冲击环和划痕。
- C 区中段的稳定平台设置自动检查点。玩家截断水流并首次安全落到该平台后，检查点由空心标记变为脉冲实心标记，屏幕提示“中段检查点已记录”。此后被尖刺、毒气击中或跌落会回到这里，并保留已经截断的水流状态；主动按 `R` 重置 C 区时才清除检查点和堵水进度。
- 上方斜向索道提供回程落脚点。最右侧是带实体踏板和摇杆的升降梯；截断水流后靠近摇杆按 `F`，升降梯上升并转入 `1-02`，不再使用抽象的“按 F 通关”。
- 区域名称仅保留在固定 HUD 中；场景内部不再重复绘制 B/C 区域标题。

## 谜题闭环

```text
看见水幕阻路
→ 看见起点附近三个外形不同的可拾取物，以及出水口的圆形内轮廓
→ 尝试拿起、调整角度并投掷
→ 错误物件被水流弹开，玩家据形状与重量修正选择
→ 石块卡入出水口
→ 水幕消失且移动落脚点启动
→ 玩家理解“场景物件可以改变环境，但需要观察并选择合适工具”
```

## 动态资源

- 玩家角色与携物动作
- 可拾取物的持有、投掷、落地和卡入状态
- 错误物件被出水口排斥的水花反馈
- 水幕流动与关闭
- 伸缩尖刺、毒气预警、喷发、受击失衡和消散
- 移动落脚点、回程索道车、出口升降梯踏板与摇杆

## 静态资源

- 悬崖与洞口轮廓
- 左右井壁和固定落脚点
- 井底岩层、固定平台、索道线和升降梯框架

静态与动态资源必须使用相同线宽、灰阶和投影规则；当前版本全部由同一个脚本绘制，不存在贴图融合问题。
