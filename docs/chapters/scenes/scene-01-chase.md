# 场景 1 · 巨影追猎：森林边的断崖（细化 v2，已确认，开始制作）

> 对应 `chapter-01.md` 的场景 1。目标：开场 25 秒左右的追逐，给整章定下**比例和压迫感**，并在最后把男孩推下崖壁，直接进入场景 2，没有切换。
> 参考《Limbo》大蜘蛛的"尺度压迫"：不靠速度，靠**只看见局部、预兆再攻击、世界被破坏**。

## 一、玩家看到什么

1. **开场：男孩躺在森林边缘的地上，然后慢慢爬起来**（复用现有的倒地、起身动作）。雾里，隔着看不见底的雾渊，对岸有**一座木屋，门前有一堆篝火**（保留原来的远景，是整章的目的地）。他爬起来往右走几步（半分钟的"安静"，让玩家看到比例和地貌）。
2. 身后的森林里传来一声铃，很远。第二声更近。树梢在晃。
3. 一只**很大的脚**从森林里踩出来，树被踩断。他看不见猎人的全身，只看见脚、手臂、一盏摇晃的灯。
4. 追逐开始：不只是跑，还要**跳和攀爬**：翻过倒木、爬上岩阶、跳过断沟，同时躲过横扫的手臂，穿过被惊起的蝙蝠，一直跑到崖边。
5. 崖边：猎人最后一击打碎崖边，男孩顺着崩塌的崖面掉进场景 2。

## 二、想问什么、线索

- 他为什么跑？铃声、脚步声、地面震动、树倒下，**不需要文字**。
- 往哪跑？地形只有一条路向右，画面右边偏上有一道很亮的断崖线，远处有那盏灯。
- 怎么躲？**地上的影子**：每次攻击前，影子先落在地上。

## 三、猎人（只看局部，两个层面）

| 部位 | 在哪 | 做什么 |
|---|---|---|
| 脚 | **前景层**（比男孩大约 10 倍） | 踩下来；踩的位置先有影子；踩过的地方留下坑和断树 |
| 手臂 | **背景层**（在男孩身后的雾里） | 横扫过来；影子先从远处一路扫到脚下 |
| 灯 | 高处摇晃 | 光扫过地面，光里的区域会被"看见"（越近越危险） |
| 铃 | 声音 | 每次攻击前一声铃，间隔越来越短 |

猎人**不是真正的 AI**，是脚本控制的演出：他的位置和攻击时刻由玩家向右的进度决定，保证玩家总是有办法躲开，也保证压迫感稳定。

## 四、追逐的时间线（起始数值，之后试玩调）

男孩跑速 135 px/s，全程 3000 px，理想用时约 25 秒。

| 进度 | 事件 | 玩家做什么 | 失败 |
|---|---|---|---|
| 0 到 300 px | 安静，铃响两声 | 往右走 | 无 |
| 300 | 第一只脚踩出森林，树断 | 跑起来 | 无 |
| 600 | **脚的预兆**：地上落下一块大影子，1.5 秒后踩下 | 在踩下之前跑过去（影子宽 220） | 被踩到：死 |
| 1000 | **倒木**横在路上（约 90 高） | **跳上去再翻过去**（攀爬）；猎人要绕，会慢一点 | 爬慢了：猎人追近 |
| 1300 | **断沟**（约 150 宽）加泥地 | **跳过去**；落在泥里会变慢 | 掉进沟里或卡泥：追近一步或死 |
| 1700 | **岩阶**：三级台阶，每级约 70 高；**手臂的预兆**：影子从背景一路扫过来，1.2 秒后扫到 | **连续攀爬**三级，或者躲进台阶下的**空心木** | 被扫到：死 |
| 2100 | **蝙蝠群**被他惊起 | 避开（蹲下不行，要跳或停） | 撞上：晕一下，猎人追近 |
| 2500 | 第二次脚，节奏更快；前面有一段**倾斜的树干**和**一根垂藤** | 爬上树干，抓藤荡过去（用刚学的绳）；脚落下前必须过去 | 死 |
| 2800 | 窄缝：猎人**伸手拨开树** | 抢在手落下前钻过去 | 死 |
| 3000 | **崖边**：他一击打碎崖面 | 起跳或者被打下去 | 无（这是出口） |

**追近机制**：有一条"猎人的手够得到的线"，从屏幕左边缘开始，随着时间向右推进，速度比男孩跑速慢一点。如果玩家停住或被拖慢，这条线追上男孩，就被抓住（死）。

## 五、被抓到、检查点、复活

- 被抓：他的手一下把男孩抓起来（死亡动画），0.8 秒后黑，从最近的检查点复活。
- **检查点每 600 px**（约 4 到 5 秒）一个，复活就接着跑，不重新开头。
- 复活时猎人已经在更近的位置，保持压迫感。

## 六、需要的动作和美术

| 项 | 内容 |
|---|---|
| 新动作视频 | 奔跑中的惊慌回头（可选）、被巨手抓起的死亡 |
| 猎人美术 | 前景的脚、背景的手臂、一盏提灯、铃（全部黑色剪影，只有灯是橙色） |
| 场景美术 | 森林（往左扩出一大块）、草坡、倒木、泥地、空心木、崖边 |
| 声音 | 铃声（越来越近）、脚步重响、断树、蝙蝠、风 |

## 七、实现上的要点（给开发看）

- 世界往左扩：场景 1 在世界坐标的负 x 一侧，场景 2 在它下面，C 区保持原来的坐标不动（需要放开镜头和玩家的 x 下限）。
- 猎人的各个部位是**脚本控制的画面元素**，不是物理角色；攻击区是矩形，由脚本在指定时刻启用。
- 影子是画在地上的暗区，在攻击前 1.2 到 1.5 秒出现并逐渐变深。
- 复用现有的：检查点、死亡与复活、镜头抖动、蝙蝠群。

## 八、留下什么状态

- 森林里留下被踩断的树、坑；崖边碎裂。
- 玩家掉进场景 2，猎人留在上面（他的手最后一次从崖边伸下来，没抓到）。
- 后面场景 2 到 5 沿崖壁一路下降，到崖脚进入场景 6：一条横向的蝙蝠洞，穿过去就是 C 区。

## 当前森林障碍反馈

石头前的弯曲荆棘（3480处）改为非致命绊倒：落地摔倒0.542秒、倒地停顿0.3秒、起身1.9秒，期间暂时锁定移动和跳跃，随后原地恢复控制。站在荆棘内不会连续触发；离开接触范围后重新进入可再次绊倒。跳跃可避开，尖刺坑仍然致命，不改变检查点和悬崖演出。
