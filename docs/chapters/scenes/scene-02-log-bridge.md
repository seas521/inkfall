# 场景 2 · 断木斜桥（可玩原型）

接在巨影追猎的悬崖下方：从崖顶沿约 600 像素长的绳梯向下爬，再蹬离落到左岸，接断木斜桥谜题。沿用原有角色控制，绳梯使用用户提供的 Seedance 视频连续抽帧。右岸现已接双路吊运站、落石栈道和原 C 区雾岸；单独的斜桥测试入口仍保留原范围。

完整连续场景入口为 `scenes/chapters/chapter_01_route.tscn`，默认从森林开场进入。DEBUG 中“章节 1 · 悬崖衔接（测试入口）”位于森林末端，保留自动行走、乌鸦和起身，再接下梯与机关；原有绳梯、斜桥的单项入口保留。后续两关各有独立 DEBUG 入口，最终沿实际地形进入原 C 区。普通检查点恢复保留机关状态，整段重置恢复森林开场和原始卡木支撑。

崖顶起身末尾（232 帧之后）到待机不再叠加旧剪影残影：两段素材的尺度接近，错位叠加会短暂加宽轮廓，再在残影消退时显得突然变瘦。取消这一处叠加，不修改角色缩放或下梯落地的过渡。

## 游玩

- DEBUG「场景 2 · 崖间绳梯（可玩）」从树林出口开始，向右走入原自动行走、停步、惊鸟和起身演出，之后恢复操作；「断木斜桥」入口保留，便于直接测试谜题。
- 崖边按 S 上梯，S 下爬、W 上爬，松开停住。顶部接翻回崖顶，支持原路返回。
- 空格蹬离绳梯，落到台阶；绳梯末端离地约 80 像素，下爬停在最后横档。返回时进入末端约 85 像素范围内按空格跳抓，包括正下方和贴近的位置，不要求固定间距或朝向；再按 W 上爬。W 单独按下不会从地面发动跳跃。
- 绳梯顶部固定，攀爬的交替承重驱动侧摆；停住后有阻尼回摆。长下爬过程约十几秒，镜头保持 1:1 随高度移动。
- 森林、绳梯、下方台阶和斜桥统一使用原场景的角色位置平滑跟随；上梯、跳抓、跳离、落地及翻回悬崖都不再切换固定机位或重新指定镜头位置。只有 DEBUG 初次进入和死亡闭幕恢复允许直接定位。
- 走近断木根部的短横卡木，按住 F，再向左移动，将卡木抽出。
- 松开 F 可以中断；已经拉出的距离保留，重新抓住可以继续。
- 原直木块改为带木质拉柄的楔形支撑，坐在与左岸连接的固定木座上。桥根下缘接触楔面；抽出时按真实接触几何求解桥角，从约 −63° 连续转到 −40°，不是小幅播放晃动动画。暂停拉动时保留楔块位置及支撑角度；斜面顶端退出接触的同一帧释放木桥，继承当前角速度，随后向右倒下。楔块使用相符的独立刚体轮廓，退出后在地面滑落。摩擦尘屑在实际接触点产生；固定木座有碰撞，避免人物穿过支撑。
- 沿断木走到右岸，保存检查点。跌落或按 R 会返回检查点，保留搭桥进度。
- 踏上木桥、行走和落地会激发受控角弹簧，图形与实际碰撞同步晃动，离开后回稳。
- 断木初次碰到对岸时，两处接触点扬起软尘，伴随细屑；本体和实际碰撞同步产生明显震颤、回弹与约一秒的阻尼衰减，镜头同时受到一次更强的地面冲击，再转为行走受力状态。扬尘和冲击发生在真实触地时刻，避免提前或重复触发。
- 普通台阶和桥上跳跃仅保留平滑垂直跟随，不在起跳或落地时震屏；下梯落地只做不足约一像素的轻微回稳，明显高频震动留给木桥撞岸与真正重落地。绳梯与斜桥独立流程不再每帧清空镜头偏移；远景保持稳定，近景地面和人物共同承受镜头冲击，保持远近层次；接触层留有额外画幅，避免震动露出矩形裁切边缘。
- Shift+R 沿用原有整幕重置，退出斜桥玩法，返回原始第一幕起点。
- 从空中最高点到落地的高度差沿用 C 区 `LETHAL_FALL`（170 像素）；中段跳下会摔死，低处末端跳下正常落地。首次下梯途中摔死返回崖顶，安全到达左岸后才保存下方检查点，已完成的搭桥状态保留。

## 实现与美术

两岸、卡木、断木分别拥有独立碰撞与图形。断木按固定支点转动，以受控角加速度倒向对岸；卡木释放后由刚体模拟。角色通过实际碰撞走过斜桥。

接触层使用近黑色剪影、轻微边缘柔化，不添加可见内部纹理；灰阶雾与远处崖体处于背景。交互物没有烘焙进背景，后续可以独立替换美术、调整尺寸与动作。

崖顶与绳梯段共享同一张岩壁剪影及世界变换；两岸使用独立岩体素材。崖底远景改为连续的山坡与雾谷，木屋落在右侧山脊的缓坡肩部，山体向左下方及画面下缘延展，没有悬挑岩棚或截断的浮岛底部。山体和木屋共享水平 0.015、垂直 0.10 的镜头视差，梯子到台阶不切换远景。按最新反馈撤除额外雾幕、人物透明度动画以及露出矩形边界的前景裁切，只保留远景画面本身的空气感。人物始终保持纯黑剪影与统一比例。

崖体自然外轮廓与内部体积分开绘制：沿最后一段连续森林地面向下封闭山体，并在岩壁素材的实心区域重叠，避免角色跟随镜头露出素材左侧裁切边界或镂空。下梯截图同时检查左侧内部像素确为近黑山体。

原森林地面的草带和草叶作为世界地形保留，不受远景切换开关控制。攀爬时它们随镜头移出画面，返回崖顶仍是同一片地面。

远处目的地恢复原美术素材：保留原不规则木屋、源图中的四格窗户、门廊、工作木架与杂物，院树按最新反馈替换为近直立、轻微 S 弯树干及不对称疏冠，保留轻微风摆。撤掉生成的简化木屋和单独绘制的窗户。原院落去掉左侧悬挑岩尖，下部埋入连续山坡；木屋、院落、树与承托山体使用同一暗色墨值，并先合入同一不透明视口，再共同经过景深和色调处理，避免独立视口导致的色差和贴片边缘。远山不限定浅灰；通过前后山脊的明暗递进组织空间。山坡明暗分区沿原素材的真实山脊采样，不以直线切出轮廓。原窗户是主目的地焦点，灰白实时篝火为次级焦点，去掉不协调的静态火堆底座。篝火、原院落与山坡共享水平 0.015、垂直 0.10 的视差，地面 UV 锚点确保上下梯不漂移。

森林图像层的树木覆盖受真实崖沿位置约束，末端柔和退出，不延伸到无地面承托的峡谷中；原 C 区中景树不再跨区绘制到这一段。近景树退出透明度直接作用于剪影材质。峡谷底图从林内就位于森林背后，林缘按固定世界位置展开，取消 `gorge_mix` 达到阈值就隐藏森林的逻辑；因此不会在崖边把整幅森林换成另一幅峡谷。

原自动行走、停步喘息、惊鸟、倒地与起身时序保留。崖边停步点前方放置小型风化木十字架和低墓堆，作为惊鸟起飞地标；墓标只是独立剪影，不新增碰撞或阻断路线，崖上与绳梯视图共享同一位置。

Seedance 主片完整保留 241 张原生连续帧，统一缩放与梯顶根节点；绿色、蓝色辅助物体去除。上下循环来自不同动作区间，不倒放。原始运动、接触点与方向衔接表记录在 `rope_ladder_manifest.gd`。生成脚本只增补梯子组，不重新打包或覆盖其他角色组。

角色尺寸沿用 C 区统一标准 `ActorPoseState.HOOD_VISUAL_SCALE`，不为斜桥或其他场景另设比例。镜头维持 1:1，包括转场；通过地形与构图调整空间尺度。`actor_scale_smoke.gd` 对 C 区各幕、巨影追猎和斜桥的同一待机帧验证实际投影尺寸一致。

- 远景：`assets/shaders/log_bridge_depth.gdshader`；`assets/art/descent/rope-ladder/destination-valley-v3.png`，内置 image_gen 制作，提示词记录于 `artifacts/rope-ladder/destination-valley-prompt.txt`。远、中、承托木屋的山脊错落叠合，控制天空留白，保持内部细节模糊。

## 验证入口

使用 Godot 4 执行 `--headless --path . --script res://scripts/demos/c_zone_debug/log_bridge_smoke.gd`，验证抓握、方向、分段拉动、搭桥、实际过桥、死亡恢复及悬崖进入。

`log_bridge_capture.gd` 在图形模式下生成 `artifacts/log-bridge/` 中的流程截图；`scene1_smoke.gd` 验证上游追猎衔接，`hood_cliff_smoke.gd` 验证原有 C 区动作。

`rope_ladder_smoke.gd` 验证真实崖边进入、下爬、悬停、持续受力晃动、跳离落地、保持同一远景且没有额外雾幕或方形前景，以及从台阶返回崖顶。`rope_ladder_capture.gd` 生成完整往返的实机截图。原视频连续帧检查和抠像预览位于 `artifacts/rope-ladder/`（不作为 Godot 游戏资源导入）。

新版院树：`assets/art/descent/rope-ladder/destination-yard-tree-v2.png`，内置 image_gen 生成的透明剪影，提示词见 `artifacts/rope-ladder/destination-yard-tree-v2-prompt.txt`。树根按源图锚点接地，视觉高度约 140 像素，完整树冠留在画面内，与木屋山体共享墨色和柔边。

`bridge_feedback_capture.gd` 录制台阶起跳落地、分段抽木、释放、桥身撞岸以及桥上跳跃的连续实机反馈，截图位于 `artifacts/log-bridge/feedback-*.png`。

`traversal_camera_smoke.gd` 在相同角色位置比较森林、桥区及六种绳梯动作的跟随结果，验证上下梯和翻回悬崖不会重定位镜头。

角色眼光在 `hood_frame_actor.gd` 中统一绘制：56 段、3086 帧共用 `hood_eye_light.gd` 的颜色和尺寸，按头部逐帧定位、随身体镜像与缩放。源图眼色与白边先清除；绳梯素材原眼睛区域存在透明孔洞，使用仅覆盖封闭内部孔洞的遮罩补回剪影，避免背景透成第二处灰白眼光。过渡残影保留自己的遮罩参数，不复制发光眼睛。实际转身、倒地与兜帽遮挡仍隐藏眼光。

绳梯眼位使用全部 241 帧原眼孔的中心，不使用残留橙色碎片的质心；后者会在孔洞两侧跳变。眼光不根据碎片主轴旋转，也不做独立于头部的世界坐标缓动，避免眼球游移与滞后。

身体材质保留原来的源图 RGB 与 alpha 叠乘，维持已验收的黑色剪影；仅封闭眼孔修补区域绕过原始透明度，不让修补处理把整个人物提亮成灰色。

台阶跳回绳梯保留源片 128–159 连续帧，按实际承重分三段：128–140 脚底固定在台阶上完成蓄力；140–147 以头部标记约束身体走一次连续抛物线，不再把摆动中的最低脚点当成身体根节点；147–159 手固定在真实横档上，随后收腿踩档。取消整段从台阶向梯子的根节点平移，避免起跳前的蹲姿已被抬到空中；绳梯受抓握的冲量在手接触时触发。`rope_ladder_catch_smoke.gd` 检查五个起跳距离的地面支撑、单次飞行、接触连续性和手部承重；`rope_ladder_catch_capture.gd` 录制近、远两种接梯过程，输出在 `artifacts/rope-ladder/catch-review/`。

`scripts/tools/build_hood_eye_tracks.py` 读取源图生成眼位，随后运行 `build_hood_eye_repairs.py` 生成内部孔洞的行段元数据；两者均不修改源 PNG。`eye_source_capture.gd -- --unified` 生成动作对照图，并检查六个绳梯姿态的修补位置没有灰白透底。`rope_ladder_actor_capture.gd` 记录上下梯回到待机后 1、8、30、90 帧及每个物理帧的角色更新次数。绳梯展示路径每帧只更新一次角色，成功交接时清除空中/落地残留状态。
