# 破墙后 · 配重运输井首版

入口：Debug「矿洞 · 配重运输井（解谜试玩）」（索引 14）。从索引 13 的旧入口破墙后也可直接向右继续。双路吊运站和落石栈道仍为独立入口。

## 实际玩法

- F 操作固定机关；按住 F 抓住矿车，配合 A/D 推拉，松开 F 放手。
- W/S 上下检修梯；S 同时保留下蹲，梯子接触范围内优先爬梯。跳跃统一空格。
- 上层试动摇杆时配重被石块卡住，会露出左侧检修口。经斜坡进入下层，推走卡住传动的石块，再经右侧检修梯返回上层。
- 矿车压下承重轨台，提升配重联动的升降笼，并打开下层隔栅。下到检修层，在受力状态下插入锁销，接管载荷。
- 返回上层取回矿车。空载承重台因锁销保持位置；未完成载荷交接，道岔与离合手柄会受阻回弹。锁销在未重新压车卸载前不可拔出。
- 操作道岔/离合使升降笼平层，再将矿车送入笼内。角色站上笼内侧后操作制动手柄，开始下行。
- 下行途中两处低横梁需提前下蹲。到井底后，经脆弱栈道和交错岩台下行，连接 C 区原有左坡。机关状态、角色比例和摄像机坐标连续。

## 复活与恢复

清障后保存解谜状态。升降阶段死亡保留解开的机械关系，返回已装车的上层笼内，由玩家重新操作制动。踏上井底出口后另设动作段检查点，避免跳跃失败重做运输井。完整重开恢复卡石、道岔、锁销、矿车和脆弱栈道。

## 图层及素材

- 控制逻辑：`scripts/chapters/mine_shaft_act.gd`；分层美术：`scripts/chapters/mine_shaft_art.gd`。
- 矿车沿用现有 Polyfork 资源，继续由同一个车体与渲染节点显示。
- 升降笼、井架、滑轮、配重和锁销由本地 Blender 脚本 `scripts/tools/blender/build_mine_shaft_kit.py` 独立制作，可单独移动。PNG 位于 `assets/art/descent/mine-shaft-v1/`。
- 连续岩井背景使用内置 imagegen 生成并复制到项目：`assets/art/descent/mine-shaft-v1/shaft-depth-v1.png`。完整生成提示词：`artifacts/mine-shaft-v1/imagegen-prompt.txt`。背景不包含交互平台、灯或机关，灯光由游戏内矿灯位置与角度控制。
- 维持现有黑色剪影、全局胶片后期和镜头暗角。新关卡美术为首版，供整体空间和可读性验收。

## 验证

- `mine_shaft_review.gd`：真实行走的上下层回路、抓车往返、装销与载荷交接条件、满载下行与复活状态。
- `mine_shaft_adventure_review.gd`：按实际速度逐跳通过岩台、动作检查点、到 C 区前后世界坐标不变。
- `mine_cart_review.gd`：原矿车抓握、后拽、撞墙粉尘与重置回归。
- `mine_shaft_capture.gd`：带完整胶片后期的上层、检修层、升降笼与出口实机截图，保存在 `artifacts/mine-shaft-v1/`。

首版可玩范围已贯通；谜题难度与图像可读性仍需实际试玩反馈，不以脚本通关代替体验验收。
