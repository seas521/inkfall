**双路吊运站**：共同观察区分出两条独立可通关路线。上路先移动滑车，使悬台同时处于前后两次跳跃的范围，再站在倾板左侧承重、按 F 将棘爪锁进承点，利用升起的远端够到高处出口。下路通过配重滑车把吊篮带回登乘高度；登篮持续握住制动柄下降，卡轨后停在左侧检修台拔出承压木条，再继续下降并跳向共同出口。检修台放在吊篮后方，避免斜降时把乘客挤入台底。任一路都不以解完另一条路为前提。

**落石栈道／崖脚洞口**：先在安全宽台看清落石周期，调节导石板，把危险转成吊篮中的配重。每一块实际接住的石头降低悬台一段，两块后形成通路，已完成状态保留。后段有 36 段逐跳验证的折返通路，混合延迟断裂的朽木、真实移动的吊板和固定岩窝。常规下降落差为 95 px，给当前跳跃高度与 170 px 致死落差留出余量。高处观察台为可选支线，发现前人遗迹不影响主线解锁。最后从高于 C 区左岸的洞口踏出，镜头随坡度逐渐回到原 C 区构图。

检查点：保留滑车、锁止、卡轨、导石配重等已知世界状态；危险落石和朽木恢复，避免试错后软锁。整段重置则恢复所有机关。操作仍为 A/D、空格、F；绳梯继续使用 W/S，不加入新角色比例或新跳跃能力。

## 世界和路线（上帝视角，见 `img/chapter1-world-map.png`）

- 一个深谷，出发的悬崖在西，对面的木屋在东；谷心是走不过去的雾渊，直线能看到木屋的灯，只能向下、再绕一个大圈。
- 路线：西边的森林与断崖 → 沿崖壁一路下坠 → 谷底的河与沼泽 → 断崖升降 → 迷雾林地 → 林冠 → 废工坊 → 山脊 → 木屋 → 地窖。
- 木屋的灯在整条路上反复出现（各种角度、各种距离），是整章的灯塔。
- **世界没有地域文化特征**（不是中国风，也不是任何现实地区），只有：灰度剪影、雾、一个弱小的披兜帽的男孩、一个始终看不清的提灯猎人、橙色只给火和灯。不用"墨"的主题，不用水做解谜（C 区已有的河保留，其他地方不再做水）。

## 统一的比例和连续性

1. **角色比例统一**：所有场景的角色缩放都用 C 区的 0.90（站立高度约 76 px）；台阶、洞口、路宽按 C 区的尺寸排（筏 144 宽，河岸宽 900）。
2. **一个连续的世界**：场景 1 到 6 在同一个世界坐标里，从崖边一路向下接上 C 区；之后各段用地貌和雾渐变相连。**取消所有黑场过场**（包括现有的升降笼到顶的渐黑）。
3. 竖直方向的物理限制：台阶之间的落差不能超过约 282 px，否则落下来会摔死（致死落地速度 920）。所以"长"要靠宽度、台阶数和段落多样性，不靠加大落差。

## 设计语法（来自《Limbo》的做法，东西全部原创）

1. **同一个东西反复换功能**：障碍 → 工具 → 武器或触发器。每一段玩家都认识它，但每次用法不同。
2. **触发点和效果点分开**，要跑来跑去才知道谁影响了谁。
3. **每个场景结束时留下状态**：倒下的树、被拉开的绳、点着的火，都留在世界里，下一段会用到。
4. **大谜题前面有 2 到 3 个小段铺垫**，每段教一个动词；大谜题只组合已学的东西。
5. **节奏交替**：喘息 → 小谜 → 追逐 → 大谜 → 追逐。
6. **死亡当反馈**：死了就在附近复活，错误的做法要能明显看出错了，正确的做法要容易执行。
7. 全章只有方向、跳、抓、投掷这几个操作。

## 场景 1 · 巨影追猎：压迫感的做法

参考《Limbo》大蜘蛛的"尺度压迫"，用我们自己的猎人：

- **只看见局部**：永远看不到猎人的全身，只有**脚、手臂、提着的灯**，从**前景和背景两个层面**进出画面，比男孩大十倍。
- **先有预兆，再有攻击**：铃声先响，他的灯先扫过来，**地上先落下手臂的影子**，影子到的位置就是要躲开的位置。
- **一次一个动作**：脚踩下来（前景），手臂从背景横扫过来，伸手拨开树。要跳过去、蹲下、躲进空心木或缝隙。
- **破坏场景**：他走过的地方树被踩断、地面被踩出坑，身后一路是被毁掉的森林。
- **声音和镜头**：铃声、脚步重响、地面抖动、碎石落下、镜头轻震。
- **被抓到就死**，马上从最近的检查点重来；这一段每 20 秒左右就有检查点。
- **中间有蝙蝠群**，被他惊起，撞上去会被打晕一下，增加紧迫感。
- **布局**：地图向左扩出一大片森林；全程约 3000 px，跑完约 25 秒；结尾崖边被他最后一击打碎，男孩顺着崩塌的崖面掉进场景 2。
- 这里猎人**可以直接杀死男孩**（取消"第一章猎人不直接伤害玩家"这一条）。

## 场景 2 到 6 · 沿崖壁下坠（要复杂一点，不是跳跳乐）

用一串不同的小段，里面反复出现的东西是**绳、栈道、绞盘、落石、蝙蝠**：

- 场景 2：落在窄台上，猎人的手扫过来，不能停；顺着**垂绳滑下去**（新动作：往下滑）；然后是猎人的旧栈道，木板朽了，踩上去会断。
- 场景 3：沿用原来的喷火台阶。
- 场景 4：卡在半路的**吊篮**，曲柄在另一个台上，转动曲柄吊篮才下来；站上去，带着人缓降。
- 场景 5：陡坡上不停滚下石头，要沿着坡往下跑，躲在凹处让石头过去。
- 场景 6：**崖脚的一条横向的长洞（约 3000 px）**，一路向右穿过去，出口就是 C 区的雾岸。洞里黑，蝙蝠被惊动要贴着岩壁躲；中间有前人留下的痕迹；从洞口出去的那一刻，第一次看清整个山谷和远处木屋的灯。场景 5 的落石断崖落到崖脚，直接进洞，没有切换。
