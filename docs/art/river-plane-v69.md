# 水面空间重构 V69

## 问题

V68将开放水域原样透射为远景，水面与空中灰雾缺乏独立关系；船体贴在其上，局部水沫不能建立整体水域。

## 实现

水面主体移入 `assets/shaders/river_plane_v69.gdshader`：同一世界平面从远处延续至前景，不再由背景水色与前侧水罩分别染色。旧远景通道仅画远处薄雾。

显式BackBufferCopy在岸体及近岸树之后、水面之前捕捉画面，用于投影反射与水下透射，避免依赖其他屏幕Shader的首次拷贝时机。映射按真实Canvas变换处理镜头缩放。水面沿纵向压缩细节，并让反射像的横向变形随缓慢斜率场变化，断续反光来自同一世界投影；没有水域照片纹理。

岸体、透明水面、船与角色、近景黑岸/芦苇按实体层组织。船和角色画在水面上，船体另按实际575入水高度衰减下侧alpha；不再通过全屏暗像素阈值猜测角色层，避免将人物当水底或被雾抹掉。船边白色接触水沫收窄，尾迹随运动方向与速度变化。碰撞、水位、划行动力与角色素材保持原状。

## 复核

原生1280×720：近岸、水中、宽镜头右岸预加载、登岸四处取景；两处运动水沫状态。沿河连续推进45帧检查空间衔接。15项局部状态与层级检查通过，日志无解析或Shader错误，git diff --check通过。未声称整章人工通关或达到原作效果。

预览与日志在 `artifacts/river-plane-v69/`；修改前未提交源文件已备份。`rollback/restore.py`默认只验证，--apply恢复V68，并拒绝覆盖后续编辑。

这是2D屏幕反射近似：画面外物件不会出现在反射里，没有三维水体模拟。原生截图是视觉判断依据，状态断言不能替代用户对水面的美术验收。
