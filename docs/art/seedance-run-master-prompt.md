# Seedance：D 角色移动主片（10 秒，一次生成）

- 首帧和参考图：`artifacts/character-concepts/hood/idle_green.jpg`（纯绿幕站立的 D）。
- 设置：10 秒，1:1，固定机位（有镜头锁定选项就打开），最高分辨率。
- 抽帧：`scripts/tools/seedance_frames.py VIDEO --name <clip> --start N --end M --fps-out 48 --loop`，默认按绿幕抠像。

## 时间轴

| 时间 | 内容 |
| --- | --- |
| 0.0–1.0s | 站立待机，轻微呼吸 |
| 1.0–2.0s | 向右起跑加速 |
| 2.0–4.5s | 向右匀速奔跑，至少 4 个完整步态 |
| 4.5–6.0s | 急停刹车，转身 180° |
| 6.0–7.0s | 向左起跑加速 |
| 7.0–9.0s | 向左匀速奔跑，至少 3 个完整步态 |
| 9.0–10.0s | 减速停稳，恢复站立呼吸 |

## 提示词

见对话中的完整版本。
