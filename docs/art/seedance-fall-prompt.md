# Seedance：D 角色跌落主片（10 秒，一次生成）

- 首帧和参考图：`artifacts/character-concepts/hood/rest_left_green_small.png`（和跳跃主片同一张：纯绿幕，朝左站立，角色高约 40%，脚底在画面 79% 处）。
- 设置：10 秒，1:1，固定机位，最高分辨率。
- 抽帧参数沿用：`--scale 0.528 --root-x 456.8 --ground-y 759 --canvas 384`（见 `scripts/tools/build_jump_clips.py`）。

## 时间轴

| 时间 | 内容 | 切成的片段 |
| --- | --- | --- |
| 0.0–0.4s | 站立静止，脚并拢 | 静止（对齐用） |
| 0.4–1.1s | 失足：脚下一滑，身体重心后仰，双臂向两侧甩起，兜帽尖向前甩 | `stumble` |
| 1.1–2.5s | 坠落：悬空，双臂向上乱挥，双腿乱蹬，衣摆和兜帽尖被气流向上吹起，位置不上下移动 | `fall_loop`（循环） |
| 2.5–3.0s | 落地撞击：快速落地，身体向前扑倒，拍在地上，轻微反弹 | `fall_impact` |
| 3.0–4.3s | 趴地不动：俯卧，头朝左，只有轻微起伏 | `downed`（循环） |
| 4.3–6.5s | 爬起：双手撑地，跪起，再站起，最后回到双脚并拢的站立姿势 | `get_up` |
| 6.5–7.3s | 站稳静止，轻微呼吸 | 静止（对齐用） |
| 7.3–8.5s | 受惊退缩：身体猛地后仰，双臂举到胸前，向后退半步，兜帽尖甩起 | `flinch` |
| 8.5–10.0s | 缓慢恢复，回到双脚并拢的站立姿势，静止 | 回到静止 |

## 在游戏里的对应
- `stumble`：险些掉落或失足的开头，接 `fall_loop`。
- `fall_loop`：坠落中（第一关竖井、失足），按下落速度一直循环，和跳跃一样由物理决定位置。
- `fall_impact` → `downed` → `get_up`：落地后按冲击速度决定播多长，`get_up` 结束回到静止姿势。
- `flinch`：被火焰、毒气、尖刺击中的短反应，也可以当成 C 区受惊的轻量版。
