# Seedance：携物（小物件 / 大物件）、挥扇、被滚石顶着后退

三条视频，分开生成，都不出现实物（哑剧），首帧都用 `artifacts/character-concepts/hood/rest_left_green_small.png`。

| 视频 | 时长 | 内容 | 切成的片段 |
| --- | --- | --- | --- |
| A 小物件（单手） | 10 秒 | 拾取、持物待机、挥扇、持物跑、持物跳、投掷 | `small_pickup`、`small_hold`、`fan_swing`、`small_run`、`small_jump_*`、`small_throw_charge`、`small_throw_release`（放下 = 拾取倒放） |
| B 大物件（双手） | 10 秒 | 深蹲拾取、抱着待机、沉重慢走、蓄力推抛 | `big_pickup`、`big_hold`、`big_walk`、`big_throw`（放下 = 拾取倒放） |
| C 被滚石顶着后退 | 5 秒 | 被撞上、顶着往后滑、停住踉跄、恢复 | `shoved_in`、`shoved`（循环）、`shoved_out` |

设计决定：
- 大物件不能跳（太重），所以 B 没有跳；A 里有一次原地的持物跳，用来拆成起跳 / 上升 / 顶点 / 下落 / 落地。
- 放下直接用拾取倒放，不单独生成。
- 物件由游戏画。抽帧后我量出"手拿东西的位置"（小物件看手的位置，大物件看胸前抱的位置），游戏里物件跟着这个位置走。

## 公共段（三条提示词都以这一段开头，再接各自的内容）

```
【最重要的规则】
整个视频里只有一个角色。画面里没有任何其他物体：没有石头、木头、箱子、扇子、绳子、墙、道具或任何东西，也没有地面线、阴影、灰尘。角色是在做哑剧：他手里拿着、抱着、托着的东西是完全看不见的，他的手只是做出握住、抱住、托着的形状，手里和手的周围是空的。不要画出、不要生成、不要暗示任何物体。

【画面与视角】
严格使用参考图中的同一个角色：黑色纯剪影、尖兜帽的小男孩，帽尖向后弯，只有一只橙色发光的眼睛，披风短袍和短裤，赤脚，无任何其他颜色、细节或描边。
这是 2D 横版平台游戏的侧视镜头：正交正侧面，镜头与角色胸口等高，完全水平，没有俯视或仰视，没有透视变化。

## A 小物件（单手，含挥扇）— 10 秒，24 帧每秒

```
【时间轴】
0.0–0.4秒：保持首帧的站立姿势，脚并拢，轻微呼吸。
0.4–1.4秒：拾取：弯膝、上身前倾，靠近镜头的那只手伸向身前地面，手指合拢像捏起一个小东西，然后站直，手停在腰前，手指弯成托着一个看不见的小物件的形状。手里是空的。
1.4–2.0秒：持物待机：站稳，那只手保持托着的形状在腰前，另一只手自然下垂，轻微呼吸。
2.0–3.4秒：挥扇：那只手像握着一个看不见的扇柄，向后上方举起蓄势，然后向前下方挥出一个大弧，带着甩出去的力量，随后顺势收回，回到腰前。身体随挥动轻微扭转。手里没有任何东西。
3.4–3.9秒：持物待机，手保持托着的形状。
3.9–5.4秒：持物跑：在原地跑，至少 6 个步子，节奏均匀，托着东西的那只手弯着放在身前，另一只手摆动。
5.4–6.6秒：持物跳：原地，先弯膝下蹲，然后向上跳起，落地缓冲，那只手始终保持托着的形状。
6.6–7.0秒：持物待机，手保持托着的形状。
7.0–7.8秒：投掷蓄力：身体后仰，托着东西的手向后拉到头后，另一只手向前伸出保持平衡，腿弯曲蓄力。
7.8–8.4秒：投掷出手：向前迈步，手从头后猛地向前甩出，手指张开，顺势甩完，手里已经空了。
8.4–9.2秒：恢复：手臂放下，身体直起，站稳。
9.2–10.0秒：站稳，回到与首帧完全一样的站立姿势：双脚并拢，双臂自然下垂，轻微呼吸，静止。

【禁止】
任何石头、扇子、球、道具或其他物体（任何颜色、任何大小、任何位置）；转身、改变朝向、镜头运动、角色大小变化、角色变形或颜色变化、出画、文字、水印、慢动作、动作停顿卡住。
```

## B 大物件（双手）— 10 秒，24 帧每秒

```
【时间轴】
0.0–0.4秒：保持首帧的站立姿势，脚并拢，轻微呼吸。
0.4–2.0秒：拾取：深蹲，两膝弯曲，双臂向身前张开下伸，然后抱住一个看不见的又大又沉的东西，身体吃力，咬牙用力，缓慢地站起来，双臂在身前抱成一个大圈，把东西抱在腹部到胸口的位置，上身为了平衡向后仰。手里和臂弯里是空的。
2.0–2.8秒：抱着待机：站稳，双臂保持抱成大圈的形状，上身后仰，膝盖微弯，胸口随呼吸起伏，吃力地喘气。
2.8–5.6秒：沉重慢走：在原地迈步，步子又短又沉，每一步身体都跟着晃一下，上身后仰，双臂保持抱着的形状，至少 5 个步子，节奏均匀。
5.6–6.2秒：抱着待机，吃力地喘气。
6.2–7.6秒：蓄力推抛：身体向后仰，双臂带着东西向后下方摆，然后猛地发力，双臂向前上方推出，向前迈一步，手臂张开放手，顺势向前踉跄半步，手里已经空了。
7.6–8.8秒：恢复：手臂放下，弯腰双手撑在膝盖上喘气，然后慢慢直起身。
8.8–10.0秒：站稳，回到与首帧完全一样的站立姿势：双脚并拢，双臂自然下垂，轻微呼吸，静止。

【禁止】
任何石头、木头、箱子、道具或其他物体（任何颜色、任何大小、任何位置）；转身、改变朝向、镜头运动、角色大小变化、角色变形或颜色变化、出画、文字、水印、慢动作、动作停顿卡住。
```

## C 被滚石顶着后退 — 5 秒，24 帧每秒

```
【时间轴】
0.0–0.4秒：保持首帧的站立姿势，脚并拢，轻微呼吸。
0.4–1.0秒：被撞上：一个看不见的巨大东西从面前（画面左侧）撞上他的胸口，他被撞得向后一顿，上身前倾顶住，双臂抬起向前抵在那个看不见的东西上，脚开始向后滑。
1.0–3.2秒：被顶着后退：他在被一个看不见的巨大东西持续向后顶，脚在地上一下一下向后蹭着退（在画面里位置基本不动，像跑步机上），至少 5 个步子，上身用力前倾，双臂伸直向前抵住，兜帽尖向前飘，吃力，节奏均匀。
3.2–4.0秒：顶力消失：那个看不见的东西停了，他失去支撑，向前踉跄半步，双臂放下。
4.0–4.6秒：站直，晃了一下后站稳。
4.6–5.0秒：回到与首帧完全一样的站立姿势：双脚并拢，双臂自然下垂，静止。

【禁止】
任何石头、球、墙或其他物体（任何颜色、任何大小、任何位置）；转身、改变朝向、镜头运动、角色大小变化、角色变形或颜色变化、出画、文字、水印、慢动作、动作停顿卡住。

## 抽帧计划（视频回来之后）
- 小物件和大物件：量"手托着东西的位置"，大物件量"双臂抱圈的中心"，写进 manifest，游戏里物件跟着它走，手不穿帮。
- 持物跑的步子节奏和跑步一样先看规不规整；持物跳按跳跃的做法拆成起跳 / 上升 / 顶点 / 下落 / 落地，由物理驱动。
- 被顶着后退：只取规整的 2 步循环做 `shoved`，跟着滚石的速度走（第一关记录的约每秒 86 像素），脚和地面不滑；前面的撞上和后面的踉跄各切一段。
- 挥扇：拿到视频里手的位置和扇柄角度，扇叶由游戏画，挂在手上。


## C 被滚石顶着后退（第二版）
