# Seedance：D 角色推拉主片（10 秒，一次生成，无实物）

- 首帧和参考图：`artifacts/character-concepts/hood/rest_left_green_small.png`（纯绿幕，朝左站立，**画面里没有任何物体**）。
- 设置：10 秒，1:1，固定机位，最高分辨率。
- 做法：哑剧式的推拉。角色对着面前一个看不见的箱子推和拉，画面里只有他一个人。游戏里的木箱由代码画在他手前面；抽帧时我量出"手停在身体前方的哪个位置、离脚多高"，木箱的侧面就放在这个位置。
- 为了不让 Seedance 加物体：参考图里什么都没有；提示词开头、每一段和禁止里都写"手前方是空的，没有任何东西"；用"推空气、推一堵看不见的墙"这样的哑剧说法。如果它还是画出了物体，换回有色箱子的方案（见文末）。

## 时间轴

| 时间 | 内容 | 切成的片段 |
| --- | --- | --- |
| 0.0–0.5s | 站立静止，脚并拢 | 静止（对齐用） |
| 0.5–1.3s | 抓握：身体前倾，双臂向前伸出到胸口高度，双手停在身体前方一个固定的位置，掌心朝前 | `grip_engage` |
| 1.3–2.0s | 抓稳：手停在同一位置，身体绷紧，轻微起伏 | `grip_hold` |
| 2.0–4.5s | 推：双臂伸直，掌心顶着看不见的墙，身体前倾，腿用力蹬地，一步一步向前，至少 4 步 | `push`（循环） |
| 4.5–5.2s | 停住，手保持在原处 | 衔接 |
| 5.2–7.7s | 拉：脸仍朝前，手指弯曲抓着看不见的边缘，身体后仰，向后一步一步退，至少 4 步 | `pull`（循环） |
| 7.7–8.5s | 停住，手保持在原处 | 衔接 |
| 8.5–9.3s | 松手：手放开，手臂放下，身体直起，后退半步 | `grip_release` |
| 9.3–10.0s | 站稳，脚并拢，静止 | 回到静止 |
