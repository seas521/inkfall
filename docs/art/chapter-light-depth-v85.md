# V85 — 实体受光、矿灯层级与船边植被连续性

本轮修复玩家反馈的灰色土包、大块岩壁灰斑、矿洞顶板浅色重复轮廓、背景灯跨层照亮人物和机关，以及船左侧植被临近才出现的问题。保留 V84 的镜头融合强度、固定世界光源、当前角色与动画。没有更改碰撞、关卡机关、死亡或检查点。

## 实现

- 土体不再按 190–260 世界像素厚度整块接收漫反射。地表肩部向内部连续衰减，埋入土中的质量保持近黑；降低土体相对于人物和可见物件的反射响应，避免灰土与黑树的拼接感。
- 没有有效地表资料的体块不再被当成无限的受光面；高处悬崖不使用下方矿洞的地形采样。空气散射排除暗色实体，避免未注册进焦点遮罩的岩壁被当成空气提亮。此实现依然是 2D 光场近似，不是完整体积或几何法线照明。
- 注册矿洞底板仅在近层遮挡之外使用干净背景。保留近岩体下面的原始暗色底板，消除膨胀遮罩与柔化轮廓不一致留下的浅色第二轮廓；远处廊道仍使用原来的分层重建，避免双重结构。
- 矿灯增加 `light_plane` 深度标记。井架房间的背景灯不再进入玩法层光源列表；同样排除篮沿的独立远灯受光路径。真正照亮操作区域的近灯加入玩法焦点组，使灯具与其影响的物件处于一致的焦点层级。
- 移除井架房间中间和吊篮上方的两盏灯，保持灯数组索引兼容；后层光场同步减去两处原有曝光和亮芯，篮沿保留微弱环境明度来辨别篮中容积。
- 船边接触草在矿洞出口预览时即存在，沿用 `river_art` 的坐标偏移，交接时不另行出现一片草。河湾世界几何不再按角色高度或相机中心作硬开关，远景水雾自身仍限定在实际水域。
