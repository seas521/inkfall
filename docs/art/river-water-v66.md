# 水面、连续远景与开场 V66

2026-11-21。响应用户实机反馈：水像贴图、亮纹铺到岸上、悬空树枝、水域与树林像两张背景切换，以及上层森林起身被挡和拉远后顶部拉伸。

## 实际修正

- 撤掉河面上方独立树冠裁片及材质分支，不再通过悬空枝叶框住画面。保留实际扎根的完整树干。
- 前景的细杆草已替换成完整的芦苇/莎草图集：弯曲茎秆、长叶、羽毛穗和密集根部，三种形态按不等间距、高度与方向布置，根部埋入近岸。素材使用内置 image_gen 生成，保存在 `assets/art/c_zone_debug/river-v66/reed-sedge-clumps.png`；完整提示词及来源见同目录 `README.md`。
- 河面远景不再使用独立湖景图片；`valley_far_v42.gdshader` 的同一森林投影贯穿水域与森林。世界空间中逐渐变化的雾降低远景对比和细节，走出水域逐步变清楚；不重建/切换一批远景树。
- `river_cove_v59.gdshader` 仅绘制远水，不覆盖天空和树林。撤去水体中的位图水纹采样、体积里的规则正弦亮纹、岸上碎光和34条无事件来源的常驻水线。
- `river_water_field.gdshaderinc` 为远水和近水提供同一低幅、连续移动的表面场；近水保留场景反射、轻微折射、浅水透射和原有真实水波。反射/波峰亮度限制在空水面，不能铺在实体岸面上。驻船的扩散波纹随真实速度/波动衰减。
- 上方森林开场的前景大树改为固定靠左布置，保留实体不透明；不会跟随玩家开透明窗。实际躺下、起身、站稳时，角色所在处的前景遮挡 alpha <0.15。
- 取消森林板片的非等比拉伸；开场远景为更远的层级采用较弱的镜头倍率响应及有效上边裁切，超出图片边界的区域不再重复钳制边缘像素。没有更改玩家尺寸、动作或碰撞。

岸体保持深黑；既有角色接收光/前侧散射实验继续关闭。水仍是二维近似，没有宣称三维流体、真实光线路径追踪或原作算法。

## 验证

- 原生 Metal/Godot 七个水域取景：15项状态及清理检查通过，原生 Shader 无编译错误。
- 森林实际等待起身并按键行走，5项检查通过；原生截图包括躺下、起身、站稳、实际拉远及0.68倍最宽取景。最宽开场采样上边界 UV 约0.0245，仍在有效图内；板片使用等比缩放。
- 从河面到森林100帧连续渲染取景扫描，查看全序列并生成影片/联系表；该扫描隐藏人物以隔离远景变化，不冒充玩家实际通关。远景始终使用同一森林节点。帧差仅用于筛查，不作为独立视觉合格证据。
- 船体空载/载人/移动/倾斜的船壳水线接触检查通过，交点误差<0.15px；未改动船体动力学。

截图、连续序列、测试脚本与日志位于 `artifacts/river-water-v66/`。视觉质感仍由用户验收；本轮不宣称全章所有构图已经逐帧通关验收。
