# 直起身（喘息之后）：Seedance 动作提示词

用在：连续跑了 3 秒以上停下来，弯腰喘息（`tired_idle`）一会儿之后，慢慢直起身站好。游戏里喘息 2.5–5 秒后触发；中途按移动键会立刻打断，所以这条要能在任意一帧被切走。素材没到之前，游戏里是弯腰的画面 0.6 秒淡成站直的画面（能用，但是是淡入淡出，不是动作）。

## 设置
- 首帧：`artifacts/character-concepts/hood/tired_bent_green.png`（弯腰喘息，就是 `tired_idle` 的姿势）。
- 如果能放尾帧参考：`artifacts/character-concepts/hood/rest_left_green_small.png`（站直的待机，游戏里 `idle_left` 的第一帧）。
- 3 秒（能选 5 秒就选 5 秒，后面空着的部分用不上），1:1，镜头锁定，最高分辨率，24 fps。

## 提示词（可直接贴）

【最重要的规则】整个视频里只有一个角色。画面里没有任何其他物体：没有地面、没有地面线、没有阴影、没有石头、没有杆子、没有任何道具、没有文字、没有字幕、没有特效。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃，不换角度。单个角色全身入镜，面朝画面左侧，脚的位置从头到尾不挪动，不迈步，不转身。

角色：头戴尖兜帽的小男孩，纯黑色剪影风格，斗篷下摆随动作轻微摆动，兜帽里只有一只橙色的眼睛。保持和首帧完全相同的造型、比例和大小，全程不变。

动作（共 3 秒，沉重、缓慢、疲惫，像一个刚拼命跑完、还没缓过来的孩子）：
0.0–0.8秒：保持首帧的姿势：上身深深前倾弯着腰，头垂着，双臂松垂，肩膀随着大口喘气一起一伏，脚不动。
0.8–1.6秒：深吸一口气，肩膀先抬起来，然后上身一点一点向上直起，背慢慢展开，头仍然低着，膝盖微微打直，动作吃力，中间有一次小小的停顿。
1.6–2.4秒：上身直起到接近站直，头慢慢抬起来，双臂自然垂在身体两侧，长长地呼出一口气，肩膀随之放松下沉。
2.4–3.0秒：站稳，呼吸渐渐平缓，身体完全静止（只有极轻微的呼吸起伏），最后一帧是站直的待机姿势：双脚站稳，双臂自然下垂，面朝左侧。

整个过程双脚始终踩在同一个位置；没有跳，没有迈步，没有抬手擦汗之类的多余动作。时长 3 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

## 接进游戏时要做的
抽帧，插帧到 60 fps，命名 `tired_rise`，起点接 `tired_idle`、终点接 `idle_left`；游戏里已经按"有这条片段就播，没有就淡入淡出"写好（`hood_frame_actor.gd` 的 `rise` 状态），打包进 `core` 组即可。
