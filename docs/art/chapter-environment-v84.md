# V84 第一章：统一环境融合与固定光源

基准为用户认可的 V83（`fusion_gain=3.0`）。本轮覆盖上方森林、悬崖／绳梯、矿车通道、井架上下层、双矿车机关、谷底森林与河岸。保持玩法、碰撞、动作根点、角色比例、镜头编排与原有检查点。

## 光源与空间

- 上方森林沿用既有世界空间林冠开口。
- 矿洞按真实灯具位置、摆角、可见性和能量收集光源，熄灭或坠落状态同步响应。井架两层实体楼板参与遮挡，阴影边界有半影。
- 谷底森林的太阳开口统一到 `chapter_sun_apertures.gdshaderinc`，在世界坐标中固定；角色、地形、道具和远景共用同一组开口。移除从随相机视差移动的远景亮度直接推导接收光的方式。
- 远景保留树形和雾的视差，但把宽幅照明与这些形体分离。光束不再被相机、玩家、变焦或动画时钟拖动。
- 地形深度按实际世界点选择，允许同一视野同时出现两个区域；不按玩家当前区域整屏更换地形身份。矿洞至 C 区预览使用真实 `(3600,-3050)` 坐标重定位，往返不另造一套光。

## 已纠正的表面问题

用户指出的“只有地皮亮、下方死黑”来自过窄的受光深度及表面增益硬切。现统一为可见岩面上的连续衰减：上部岩面可受光，越深逐渐回到暗部，保持黑色重量。草、角色与道具仍在同一入射光场中；不使用白色贴层、折射、重影或假法线。

脚边原本以物理胶囊脚点为中心压低 85% 新增受光，容易与地表衰减叠成黑缝。现读取当前实际动画帧的可见脚底，只有落地时提供小范围、12% 的柔和接触压暗；去掉地表处的窄硬切。

去掉地形有效性 0.5 阈值造成的材料跳档；矿洞的“无下层地板”100000 哨兵值不再与真实地板高度插值，避免生成虚假深度和竖向亮条。楼板端点的下层受光深度采用平滑过渡。

水不再把整束入射光直接截断；水下的材质与空气响应分别连续衰减。水色、透明感、船体吃水和水体碰撞不重做。

## 验证与产物

- 11 处原生取景、49 项运行检查：区域启用、V83 强度、根点／比例、真实矿灯、灭灯、井架分层、坐标交接、菜单隐藏和回到游戏。
- 6 项真实图像／行走检查：地皮以下的岩面像素确实受光，深部保持暗色；行走不锁住，脚底接触跟随；水下色彩不被岩面处理覆盖。该回放仅在本地 QA 启动脚本中使用“已通过落石陷阱”状态，正常关卡没有取消落石。
- 7 项 GPU 光场检查：同一亮部和半影世界点，在玩家移动、镜头平移及拉远后光照保持一致；扫描谷底森林全长光场，无硬竖向截断。半影点样本约 `0.439148/0.439148/0.439135`；每像素最大连续变化约 `0.007324`。
- 原生截图、真实行走取样、光场记录与启动脚本均在忽略目录 `artifacts/chapter-environment-v84/`，不进入游戏资源。最终静态截图不是完整人工通关证明。

这是一套受实际光源和几何约束的 2D 美术呈现，不宣称完整三维 GI、真实材质法线或任意动态几何的完整投影。原 V56 接收光和传输实验仍关闭，没有把它们重新整组打开。
