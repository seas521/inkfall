# 左岸水下硬轮廓 V70

用户指出左岸斜坡露出一块没有浸水的尖岩。检查发现两处叠加：

- 玩家层接触草的跨度延伸到x1230，沿水下碰撞坡面生成，且前后草层在水面上方，形成看似岩石的黑色斜边。现按整丛根部范围检查真实水位，水下不再生成干岸草；对岸同用此规则。碰撞保持不变。
- 水面已模糊透射像，但仍使用较硬的干岸高度遮罩相乘，重新形成清晰对角边。现将水下遮罩过渡宽度与采样失焦随深度增加，同时缩短深部对比保留距离。

保留贴水的浅层岸体，深部连续融入同一水面。原生复核增加左岸入水点，覆盖左右岸、船上与离开水域。截图、日志及本轮修改前未提交文件位于artifacts/river-bank-v70；rollback/restore.py默认只校验，--apply恢复V69并拒绝覆盖后续编辑。
