## 画面意图

玩家、脚下实体与当前交互物是稳定的玩法层；林间亮雾、矿洞深处和贴近镜头的遮挡继续保留各自的失焦。用户所说“从水滴中看世界”的观感由远近失焦、亮处的柔和扩散、空气层与暗部围合共同维持，不新增字面上的水滴、折射波纹或扭曲角色。

本轮减少重复扩散，不增加锐化或提高全屏曝光。不改人物尺度、碰撞、关卡布局、机关物理、检查点和相机倍率。本轮包含三种环境下的共享受光与动态方向；大型区域变焦尚未调整，不能宣称已经完成全部镜头语言优化。

## 已接入

- 将原先 C 区人物附近的覆盖遮罩扩展到上方森林、悬崖、矿洞和谷底森林；每个区域只收集明确的玩法实体。
- 将狭窄贴随人物的径向范围替换为宽幅活动区：角色、附近地面和物体共同清楚，外围逐渐柔化。矿洞井架、双车接力有各自宽幅焦点组，关联部件保持可读；全程与真实物件覆盖相交，背景不进入清晰窗口。
- 最终 Film 在真实物件覆盖内使用较小的扩散核和较轻混合；背景继续沿用原有的大尺度柔化、亮部扩散、暗角与颗粒。
- 角色源材质的柔化半径在该层启用时降为原来的 38%，保留抗锯齿和少量柔边；不修改动画帧、透明裁切和根节点。
- 墨色地形与草皮的源柔化分别调整到 1.0 / 1.2；上方森林草皮从屏幕覆盖层移回真实世界坐标，纹理预柔化改为固定小核，取消以屏幕 Y 当距离的旧写法。角色、脚下草皮与地面一起进入活动区景深；镜头前草丛独立失焦，不全部锐化。
- 矿洞只收集结构/地面透明分层、车、绳、井架部件、摆锤与控制器；不收集不透明远墙，也不收集在矿洞绘画后方不可见的外部大山体。
- 区域切换会解除旧覆盖位，章节隐藏时停止遮罩更新并恢复源材质，退出时释放自己添加的可见层标记。
- 按用户要求取消 F10 后处理开关，最终美术效果默认保持开启。原型注释和旧文档中的按键说明同步更新。

活动焦点在世界坐标中缓动，普通台阶和跳跃保留竖向死区，不每落一脚重对焦。

复用一张 640×360 的共享 World2D 遮罩；不复制关卡、动画、物理或矿车 3D 视口。新脚本只用于内部验收，没有增加公开 debug 菜单入口。

## 将视频观察对应到当前游戏

| 参考中的关系 | 游戏中的具体应用 | 可复核位置 |
| --- | --- | --- |
| 角色当前区域相对明确，向外围和深处变软 | 世界坐标活动焦点＋真实玩法物件遮罩；关联机关组成焦点组 | 森林亮隙、井架上下层、双车区、C 区落脚点 |
| 远景内部也有虚实与明暗层次 | 保留既有森林分层；禁止焦点命中背景图或矿洞后方不可见山体 | 森林中远树、矿洞后廊道、C 区远林 |
| 草不是全画面同样清楚或同样模糊 | 脚下草与地面进入同一焦点，极近草丛仍独立失焦；相机平移不改变源图模糊核 | 上方林地、悬崖边、矿洞出口植被、C 区坡地 |
| 林间明暗由开口和遮挡组织 | 上方森林用三个与既有林间亮区对应的定向受光区域，叠加缓慢林冠遮光；C 区继续采样其远景开口场 | 上方暗林到亮隙、C 区河岸与后段持石头处 |
| 人物属于光照空间，不永远死黑 | 角色材质按世界方向做宽度不均的局部迎光变化；镜像后光向仍正确，暗侧保留 | 空手和持石头，接收光 on/off 对照 |
| 吊灯真正影响附近环境 | 读取实际灯泡位置、灯罩朝向与熄灭状态，传给人物与近空气/道具；上、中层工作平台阻断穿透光 | 井架吊灯左右摆角、入口灯掉落状态 |
| 光落到地面，会被物体挡住 | 真实地面一维轮廓＋玩法覆盖＋短距离屏幕采样；水和断口不生成发亮地面 | 灯下地面、C 河面、岛间断口 |
| 亮区柔润而主体有重量 | 保留最终亮部散射、远近独立失焦、空气与暗角，不增加水滴贴图或画面折射 | 三个区域的原生画面对照 |

这些是 Inkfall 为达到观感所选的近似实现，不是原作引擎参数。上方森林的林冠受光区域为当前场景人工安排；矿洞的工作平台遮光和局部接触阴影不等同于对所有场景几何作完整光线追踪。

## 共享受光实现

`chapter_light_field.gdshaderinc` 为角色和环境接收层共享源位置、方向、距离衰减与平台遮挡。森林保留林冠穿插造成的变化；矿洞从真实吊灯收集最多八个邻近源，并降低后方灯对玩家平面的贡献；C 区沿用与远林匹配的开口采样。

地面轮廓按森林、矿洞、悬崖、谷底分别缓存；矿洞下层地面独立参与接收，避免跨层误投射。新增近空气只用少量、受光区约束的薄雾和稀疏微尘衔接已有主光体积，不全屏加白。角色的受光加在黑色源图乘色之后，不改脸部裁切、体型、动作或原始 alpha。
