# 崖下五个空间 · 静态美术巡览

2026-11-06。衔接巨影追猎崖边与原有 C 区。当前是静态构图巡览；未实现滑绳、吊篮、落石和蝙蝠机关，也不是完整可玩的下降地形。

美术基准：已验收的巨影追猎前段、整个 C 区及《Limbo》的模糊剪影语言。质感来自低频体积、遮挡、空气和自然轮廓；不可读清木纹、岩石颗粒、绳结或篮筐编织。用户已否定初版简单几何与第二版直接展示写实纹理的观感。

- 五张独立底板通过内置 imagegen 生成，保存在 `assets/art/descent/01…05-…-v2.png`，不使用旧 B 区素材。
- 源底板作为材质与轮廓输入，不代表最终观感。游戏内通过 mip 链和二维高斯采样去除高频，再压缩暗部纹理、柔化轮廓。最终以 `artifacts/descent/01.png` 至 `05.png` 的引擎截图为准。
- 每张底板以明度掩膜分成失焦远层、材质中层、深色近层，叠加独立体积光、缓慢双层雾与少量动态尘埃。此阶段是影像分层，不是逐件抠出的机关资源。
- 巡览由连续位置驱动底板交叉淡化。后续可玩地图需要另外拆解环境部件、建立碰撞与交互；巡览不假装已有这些玩法。
- 男孩使用现有 Seedance 帧动画，在各主构图停留时作为比例参照；镜头移动和洞口过渡时不摆放悬空参照角色。
- 接近 C 区时逐渐露出原有背景与地形，新底板在 x=-120 时贡献为零。出口补齐接触轮廓，避免暴露原河岸的竖直起始边；C 区玩法继续使用原控制器。

## 查看

启动游戏后按 Esc，在 DEBUG 菜单选择“场景 2～6 · 崖下美术巡览”。也可从巨影追猎崖边坠下进入。

左右键或 PgUp/PgDn 选择空间，上下键沿途查看，空格自动巡览，F6 隐藏或显示说明。抵达末端后按 F 进入原有 C 区玩法，Esc 返回菜单。

## 生成提示集

使用内置 imagegen，非 CLI；每个空间独立生成，不使用一张背景重复拼贴。共同提示约束：16:9、无角色、无 UI/文字；侧面构图；灰度；自然侵蚀轮廓；雾中远景；不规则老木与根系；无重复树形与背景支架。源图允许材质信息供后续降频，最终显示必须遵守上面的模糊剪影标准。

1. `01-broken-walkway-v2.png`：森林崖下断裂旧木栈道，左侧岩体与根系上悬，主平台位于画面约七成高度，破木梁垂绳，右侧雾谷；无重复背景树或支架。
2. `02-wet-recess-v2.png`：下降到潮湿内凹崖腹，巨大根系与岩顶，非对称石沿、垂绳、开口落雨；不出现木架与起重设施，亮雾位于主落脚点后方。
3. `03-hoist-station-v2.png`：根系吞没的废弃吊运站，扭曲巨木作悬臂、石配重、旧绳盘、开放货篮；对岸为凹曲侵蚀崖壁，避免复制断栈道构图。
4. `04-scree-chute-v2.png`：从左高右低的连续碎岩斜廊，两处侵蚀岩凹、稳定落在坡面的巨石、右下方洞口；没有漂浮踏板或漂浮石头。
5. `05-bat-cavern-v2.png`：横向低矮崖脚洞，三层侵蚀拱壁、几簇形态不同的倒挂蝙蝠、左侧旧拖橇；右侧明亮出口露出与现有 C 区相容的柔软树影和雾岸。

源图生成参考为现有森林截图与本轮前序素材；洞穴另参考实际 C 区截图，以约束出口方向与灰度。最终运行时不展示源图的可辨认写实细节。
