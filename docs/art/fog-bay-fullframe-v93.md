# 雾湾水域 Demo · 全画幅 V93

入口：运行时关卡菜单 / 编辑器 DEBUG 下拉的「测试 · 雾湾行船与绳梯」（序列化启动值19）。
场景：`res://scenes/debug/fog_bay_playable_v91.tscn`。

当前版本保留已认可的浅滩、高岸、雾中远景、船体、承重浮力、动态倒影和旧绳梯。
画面按窗口比例等比覆盖，16:9适当裁切左右，超宽屏接近完整横向构图；镜头缓慢横向跟随，始终限制在1914×822原始画布内部。没有额外拼接、镜像边缘、非等比拉伸或上下黑边。
人物、船和实时倒影以3828×1644离屏缓冲、1914×822逻辑空间绘制，最终画面由实际窗口视口渲染。

操作：A/D移动，空格跳跃，F拾取扇子/抓拖绳，E挥扇，W/S攀爬，R重置，Esc返回菜单。
船靠近右岸后，走到绳梯下方原地跳抓；攀爬、上下岸使用既有绳梯动作。顶部旧木桩固定双侧梯绳，梯子按受力摆动。当前跳抓仍为既有素材适配，专门的垂直伸臂抓梯Seedance素材待提供。

本版本为独立Demo，尚未接入第一章主路线。矿洞出口、取扇、拖船入水与上岸回森林的连续镜头接入，按用户要求暂缓，待全画幅验收后继续。

验证：Godot原生运行检查16:9、16:10、超宽屏逆变换视域均未超出美术边界；承重船上站立正常。先前已验证连续挥扇不沉船、绳梯上下往返、攀爬暂停继续和每帧单次角色更新。美术位图哈希与接入前基线一致。
