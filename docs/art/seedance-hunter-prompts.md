# Seedance：猎人（场景 1 的追逐）

四条视频，分开生成，首帧都用 `artifacts/character-concepts/hunter/hunter_right_green.jpg`（猎人朝右，纯绿底，完整入镜）。

| 视频 | 时长 | 内容 | 切成的片段 |
| --- | --- | --- | --- |
| A 行走（循环） | 5 秒 | 缓慢沉重地原地迈三步，最后回到首帧姿势 | `hunter_walk`（循环） |
| B 踩踏 | 5 秒 | 站稳，一条长腿抬高、停顿瞄准，尖脚狠狠扎下，停住，慢慢收回 | `hunter_stomp_up`、`hunter_stomp_down`、`hunter_stomp_out` |
| C 伸手 | 5 秒 | 站定前倾，提灯的长手臂缓慢伸出，手指张开，向下一压，停住，收回 | `hunter_reach_out`、`hunter_reach_press`、`hunter_reach_back` |
| D 站立待机 | 3 秒 | 站着，轻微起伏，灯笼和布条轻晃 | `hunter_idle`（循环） |

设计决定：
- 猎人在游戏里是男孩的 8 到 10 倍高，永远不会整个人出现在画面里：背景里走的时候他在雾里（虚化、发灰，只露出腿和灯），踩踏时只有腿和脚在前景，伸手时只有手臂和灯。所以视频里要拍的是**整个人**，我抽帧后按场景裁剪。
- 灯笼的橙色火焰是画面里唯一的颜色。游戏里的灯光和光晕由游戏画，抠绿后只留黑色剪影和灯笼本身。
- 他没有脸：兜帽里始终是黑的，不要生成眼睛或五官。
- 他的动作要**慢而沉**，预备慢、落下快而狠、收回慢，这是压迫感的来源，不是速度。

## 公共段（四条提示词都以这一段开头，再接各自的内容）

```
【最重要的规则】
整个视频里只有一个角色。画面里没有任何其他物体：没有地面线、没有阴影、没有石头、没有树、没有雾、没有灰尘、没有文字、没有字幕、没有特效。角色手里只有一盏小灯笼，除此之外没有任何道具。

【画面与视角】
严格使用参考图中的同一个角色：一个极其高大瘦长的猎人，纯黑色剪影。他佝偻着身体，躯干窄而驼，两条腿又长又细，膝盖是尖锐的棱角，脚尖尖细；身上挂着破烂的布条和绳子；头藏在破烂的兜帽里，兜帽里是纯黑一片，看不见脸，没有眼睛，没有五官。他一只长手臂向前下方垂着，手里用链子提着一盏小铁灯笼，灯里是一小团橙色火焰，这是画面里唯一的颜色。除此之外没有任何其他颜色、细节或描边。
这是 2D 横版平台游戏的侧视镜头：正交正侧面，镜头与人物腰部等高，完全水平，没有俯视或仰视，没有透视变化。
背景为平整的纯绿色（#00FF00）绿幕。
镜头完全固定：不推拉、不摇移、不抖动、不缩放。
角色始终朝向画面右侧，不转身。
角色在画面中的位置基本固定，像在跑步机上：走的时候脚在地上迈步，但身体在画面里的位置不变。
角色在画面中的大小始终与首帧一致，整个人（从头顶到脚尖）始终完整在画面内。
站立时脚尖始终回到首帧脚尖所在的同一条水平高度（画面约 93% 处）。
只有两条腿和两条手臂，不要多出腿、手臂或手指。
二维动画质感，动作有重量感，布条、斗篷下摆和灯笼有惯性跟随。动作整体缓慢沉重，不要快，不要重复帧，不要卡顿。
```

## A 行走（循环）— 5 秒，24 帧每秒

```
【时间轴】
0.0–0.4秒：保持首帧的姿势，身体极轻微地起伏，灯笼轻轻晃动。
0.4–1.7秒：第一步：靠后的那条长腿慢慢抬起，膝盖弯曲，向前伸出，尖脚缓缓落到前方地面，落地时有一次明显的顿挫，身体随之向前微沉；灯笼随步伐前后摆动，布条被带起后缓缓落下。
1.7–3.0秒：第二步：另一条长腿同样缓慢地抬起、向前、落地，落地时顿挫，身体微沉，灯笼摆动，布条飘动。
3.0–4.3秒：第三步：第一条腿再次抬起、向前、落地，节奏、幅度和前两步完全一致。
4.3–5.0秒：身体稳住，两脚站稳，灯笼摆动逐渐平缓，最后一帧回到首帧的姿势（两脚的位置和首帧一致）。

整个过程像一个庞然大物在雾里缓慢逼近：每一步都沉重、克制、带着不可阻挡的压迫感；不是奔跑，不是潇洒地走。身体在画面里的位置基本不变（原地迈步，像在跑步机上）。时长 5 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。
```

## B 踩踏 — 5 秒，24 帧每秒

```
【时间轴】
0.0–0.5秒：保持首帧的姿势，两脚站稳，身体轻微起伏，灯笼轻晃。
0.5–1.7秒：身体微微后仰，靠前的那条长腿缓慢抬起，膝盖越抬越高，直到大腿接近水平，脚尖悬在空中；灯笼被带得向后摆。
1.7–2.3秒：腿停在最高处，一动不动，像在瞄准；身体前倾，灯笼摆回来、轻轻晃动。
2.3–2.6秒：这条腿猛地、笔直地向下踩去，尖脚扎向地面；身体随之向前一沉。
2.6–2.8秒：踩下的瞬间：脚扎在地面上，布条和斗篷下摆被气流猛地向上甩起，灯笼剧烈地向前甩荡。
2.8–3.6秒：踩下后保持不动，布条和灯笼慢慢落下、晃动渐渐平缓。
3.6–4.6秒：脚缓慢地从地面抬起，收回到身体下方，身体慢慢回到首帧的站姿。
4.6–5.0秒：站稳，身体静止（只有极轻微的起伏），最后一帧回到首帧的姿势。

整个动作要有重量和压迫感：预备慢、落下快而狠、收回慢。支撑腿（后面那条）始终站在原地，不动。身体在画面里的位置基本不变。时长 5 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。
```

## C 伸手 — 5 秒，24 帧每秒

```
【时间轴】
0.0–0.5秒：保持首帧的姿势，双脚站稳，灯笼轻晃。
0.5–1.6秒：身体缓缓向前倾，头低下去，像在俯视脚下很远处的东西；提灯笼的那条长手臂先慢慢向前抬起，灯笼在手下缓慢晃动。
1.6–2.8秒：长手臂继续向前下方伸出，直到几乎伸直，手指一根一根缓慢张开，手掌朝下，悬在半空；灯笼在手腕下晃动，布条从手臂上垂下。
2.8–3.3秒：手掌悬停不动约半秒，像要把什么按住。
3.3–3.5秒：手掌猛地向下一压，然后停住。
3.5–4.4秒：手臂缓慢地收回，手指缓缓合拢，身体缓缓直起。
4.4–5.0秒：站稳，身体静止（只有极轻微的起伏），最后一帧回到首帧的姿势。

整个过程缓慢、克制、带着不可抗拒的压迫感，只有最后那一压是快的。双脚的位置始终不动。身体在画面里的位置基本不变。时长 5 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。
```

## D 站立待机（循环）— 3 秒，24 帧每秒

```
【时间轴】
0.0–3.0秒：保持首帧的站姿，两脚站稳不动。身体随着缓慢的呼吸极轻微地起伏（上身一点点抬起、一点点落下），头微微低着，提灯笼的手臂几乎不动，灯笼在链子下缓慢地小幅晃动，破布条和斗篷下摆被无形的风带得轻轻飘动。

最后一帧和第一帧完全一致，方便循环。动作极轻、极慢。时长 3 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。
```

## 接进游戏时要做的
- 抽帧，抠绿，插帧到 60 fps，打包成 `hunter` 组的片段；游戏里的猎人是脚本演出（`hunter_act.gd`），事件时刻不变，只把 `hunter_art.gd` 里几何画的灯和剪影图换成这些片段。
- 背景里的行走：用 `hunter_walk`，放大到约 10 倍男孩高，虚化，压低对比度（灰一点），只露出腿和灯，其余在雾里；和玩家距离越近越大、越清晰。
- 脚的攻击：用 `hunter_stomp_*` 裁出腿和脚，放在前景层，预兆影子、冲击时刻不变。
- 悬崖那一掌：用 `hunter_reach_*` 裁出手臂和灯，放在悬崖前景。
- 灯笼的光晕由游戏画（叠加在抠出的灯笼上），所以抠绿时灯笼火焰保留，灯笼外的绿色全部去掉。
