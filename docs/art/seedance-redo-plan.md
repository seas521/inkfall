# 动作衔接评估与重做方案（首尾帧）

## 评估：问题不在某一个动作，在"每段视频的结尾都不是下一段的开头"

每段 Seedance 视频我都只给了**首帧**图，没有给**尾帧**图，所以每一段视频的结尾姿态、体型都是它自己生成的，和游戏里下一个要接的动作对不上。以前遇到一处接不上就改一处（加淡入淡出、加缓动、改切点），淡入淡出只是把两个不同的轮廓叠在一起，所以越改越乱。

`scripts/tools/audit_transitions.py` 把游戏里每一个"A 的最后一帧 → B 的第一帧"按脚底对齐，量轮廓差异和身高比（打包前的原始帧；同一段视频里连续两帧的正常差异大约 15–25%，所以超过 40% 就是一次肉眼可见的跳变）：

| 连接 | 差异 | 身高比 | 判断 |
| --- | --- | --- | --- |
| 待机 → 起跑 | 4% | 1.00 | 好（起跑第一帧就是站直） |
| 起跑 → 跑循环 | 23% | 1.01 | 好（正好隔一个源帧） |
| 刹停末帧 → 弯腰喘息 | 4% | 1.01 | 好（同一段视频） |
| 弯腰喘息 → 直起身第一帧 | 22% | 0.99 | 一般 |
| 待机 → 原地起跳第一帧 | 108% | 0.73 | **跳**：起跳第一帧已经是深蹲，待机直接切过去 |
| 原地落地末帧 → 待机 | 52% | 1.06 | **跳**：视频里落地后接的是起跑，没有"站稳"这一段 |
| 跑动落地末帧 → 待机 | 161% | 1.10 | **跳**：同上，末帧还在跑 |
| 跑动落地末帧 → 跑循环 | 80% | 1.02 | **跳** |
| 跑循环 → 跑动起跳第一帧 | 75% | 0.92 | **跳** |
| 空中下落末帧 → 落地第一帧 | 70–78% | 0.9 | 落地的瞬间姿态突变（起跳段和落地段是不同帧抠出来的） |
| 空中 → 攀爬第一帧 | 70–87% | 0.8 | **跳** |
| 直起身（旧版）末帧 | — | 1.08 | 视频里站得比待机高 8%，还有先拉长再缩短的过冲 |
| 攀爬（旧版）末帧 | — | — | 佝偻着站、背鼓起来，要再接一段起身 |

结论：站立、跑动、喘息这一组（视频 a）彼此是接得上的；**跳跃（视频 b）、攀爬（视频 e）、直起身（视频 f）**和待机 / 跑循环的接缝都不行，靠后期修不干净。现在游戏里的临时做法（`tired_rise` 和 `climb` 末尾用 RIFE 变形到待机那一帧）只能把接缝藏进去，不是动作。

## 解决：先定"锚点姿态"，每一段视频都从一个锚点出发、回到一个锚点（首帧 + 尾帧都给图）

| 锚点 | 图 | 来源 |
| --- | --- | --- |
| A0 站直待机 | `artifacts/character-concepts/hood/rest_left_green_small.png` | 游戏里 `idle_left` 的原图 |
| R0 跑循环起点 | `artifacts/character-concepts/hood/run_loop_green.png` | 现在 `tired_run` 的第 0 帧（视频 a 的第 51 帧） |
| P0 弯腰喘息 | `artifacts/character-concepts/hood/tired_bent_green.png` | 现在 `tired_idle` 的姿势 |
| 攀爬前 | `artifacts/character-concepts/hood/climb_first_blue.png` | 站在蓝色方块前 |
| 攀爬后 | `artifacts/character-concepts/hood/climb_last_blue.png` | 同一个方块，他站直待机（A0）站在方块上沿，脚踩在上沿线上 |

所有图都是 960×960，脚底在 y=759、脚的位置相同、大小相同（站直 377 px 高）。

要重做的 4 段（每段的提示词是完整的，直接粘贴；首帧和尾帧在视频生成界面各放一张图）：

| 视频 | 首帧 → 尾帧 | 时长 | 取代 |
| --- | --- | --- | --- |
| 1 直起身 | P0 → A0 | 3 秒 | `tired_rise` |
| 2 原地小跳 | A0 → A0 | 4 秒 | `clumsy_stand_*` |
| 3 跑动中小跳 | R0 → R0 | 4 秒 | `clumsy_run_*` |
| 4 攀爬 | 攀爬前 → 攀爬后 | 5 秒 | `climb` |

其余动作（起跑、跑循环、刹停、喘息）保持视频 a 不动。

## 通用规则（每条提示词里都写了）
- 一个角色，纯绿色背景（攀爬视频里再加一个纯蓝色方块），镜头不动，脚的位置不挪，不转身。
- **体型全程不变**：和首帧、尾帧里的大小完全一样，不能忽大忽小，不能中途变高变矮。
- 第一帧和最后一帧就是给的图（姿态、大小、位置一致）。
- 动作少、利落：只做需要的动作，没有多余的小动作（不擦汗、不乱蹬腿、不爬行、不拉伸）。

## 接进游戏时要做的
- 抽帧后先看是不是每个姿势占两帧（上一批的直起身视频就是，要去重再插帧，否则会卡顿，`build_rise_clip.py` 里有现成的去重）。
- 首尾帧给了图，接缝就是同一个姿势，不用再做变形或淡入淡出；跑 `scripts/tools/audit_transitions.py` 看接缝差异、身高比，超过 12% / 4% 的不用。
- 起跳段按物理速度选片段（起跳 / 上升 / 顶点 / 下落 / 落地）：落地片段的末帧回到 A0 / R0，所以落地之后直接接待机 / 跑循环。

## 提示词

### 视频 1：直起身（P0 → A0，3 秒）
首帧：`tired_bent_green.png`；尾帧：`rest_left_green_small.png`。

【最重要的规则】整个视频里只有一个角色。画面里没有任何其他物体：没有地面、没有地面线、没有阴影、没有道具、没有文字、没有字幕、没有特效。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃，不换角度。单个角色全身入镜，面朝画面左侧，脚的位置从头到尾不挪动，不迈步，不转身。

角色：头戴尖兜帽的小男孩，纯黑色剪影风格，斗篷下摆随动作轻微摆动，兜帽里只有一只橙色的眼睛。第一帧是给定的首帧图（弯着腰喘气的姿势），最后一帧是给定的尾帧图（站直待机的姿势）。角色的大小从头到尾必须和这两张图里完全一致：不能变大，不能变小，不能被拉长再缩短，站直时的高度就是尾帧图里的高度，不会比它更高。

动作（共 3 秒，只有一个动作：从弯腰直起身，一次完成，不重复，不拉伸，不抬手）：
0.0–0.5秒：保持首帧弯腰的姿势，肩膀随呼吸轻轻起伏；
0.5–2.2秒：上身一次性、平稳地直起来，背展开，头抬起来，双臂自然下垂，节奏沉但不拖，中间没有停顿，没有过冲（不会站得比最终姿势更高再落回来）；
2.2–3.0秒：到达尾帧图里的站直待机姿势，之后身体基本静止，只有极轻微的呼吸。

整个过程双脚始终踩在同一个位置；没有跳，没有迈步，没有擦汗、伸懒腰、甩手之类的多余动作。时长 3 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

### 视频 2：原地小跳（A0 → A0，4 秒）
首帧和尾帧都是：`rest_left_green_small.png`。

【最重要的规则】整个视频里只有一个角色。画面里没有任何其他物体：没有地面、没有地面线、没有阴影、没有道具、没有文字、没有字幕、没有特效。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃，不换角度。单个角色全身入镜，面朝画面左侧，不转身。

角色：头戴尖兜帽的小男孩，纯黑色剪影风格，斗篷下摆随动作轻微摆动，兜帽里只有一只橙色的眼睛。第一帧和最后一帧都是给定的图（站直待机的姿势）。角色的大小从头到尾必须和给定图里完全一致，不能变大变小。

动作（共 4 秒，只跳一次，又累又笨拙，不是灵巧的跳）：
0.0–0.5秒：站着不动，和首帧一样；
0.5–0.9秒：膝盖弯下去，上身略前倾，准备起跳（下蹲不要太深）；
0.9–1.6秒：低低地跳起来，脚离地的高度大约只有他自己身高的三分之一到一半，手臂笨拙地往两边晃一下，在空中姿势有点僵；
1.6–2.1秒：落地，膝盖一软，上身往下沉一下，落地发沉；
2.1–3.4秒：慢慢站直，回到给定图里的站直待机姿势；
3.4–4.0秒：保持站直待机不动，和尾帧一样。

脚落地的位置和起跳的位置一样（原地跳，不往前走）。没有多余的动作，没有转身，没有挥手。时长 4 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

### 视频 3：跑动中小跳（R0 → R0，4 秒）
首帧和尾帧都是：`run_loop_green.png`（疲惫慢跑的一个姿势）。

【最重要的规则】整个视频里只有一个角色。画面里没有任何其他物体：没有地面、没有地面线、没有阴影、没有道具、没有文字、没有字幕、没有特效。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃，不换角度。单个角色全身入镜，面朝画面左侧，不转身。角色在画面里的水平位置从头到尾基本不变（像在跑步机上：身体不往前移动，只有腿在跑）。

角色：头戴尖兜帽的小男孩，纯黑色剪影风格，斗篷下摆随动作轻微摆动，兜帽里只有一只橙色的眼睛。第一帧和最后一帧都是给定的图（慢跑中的姿势，上身前倾，一只脚在前一只脚在后）。角色的大小从头到尾必须和给定图里完全一致，不能变大变小。

动作（共 4 秒，疲惫的慢跑，每秒大约 1.6 步，沉重，不是轻快的冲刺）：
0.0–1.0秒：和首帧一样的慢跑，保持同样的步频；
1.0–1.5秒：身体向下沉一点，准备起跳；
1.5–2.2秒：低低地跳起来，双脚离地的高度大约只有他自己身高的三分之一到一半，两腿在空中保持跑的形状，手臂笨拙地晃；
2.2–2.8秒：落地，上身往下沉一下，落地发沉，马上接着跑；
2.8–4.0秒：回到和首帧一样的慢跑，步频不变；最后一帧回到和首帧完全一样的姿势（同一个相位）。

没有多余的动作，没有转身，没有挥手，没有加速。时长 4 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

### 视频 4：攀爬（攀爬前 → 攀爬后，5 秒）
首帧：`climb_first_blue.png`；尾帧：`climb_last_blue.png`。

【最重要的规则】整个视频里只有两样东西：一个角色，和一个纯蓝色的方形平台（画面左半边那个，位置、大小、颜色在整个视频里都不变，不能动，不能变形）。没有任何其他物体：没有地面、没有地面线、没有阴影、没有道具、没有文字、没有字幕、没有特效。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃，不换角度。单个角色全身入镜，面朝画面左侧（面向蓝色平台）。

角色：头戴尖兜帽的小男孩，纯黑色剪影风格，斗篷下摆随动作轻微摆动，兜帽里只有一只橙色的眼睛。第一帧是给定的首帧图（他站在蓝色平台前），最后一帧是给定的尾帧图（他站直待机，脚踩在蓝色平台上沿）。角色的大小从头到尾必须和这两张图里完全一致：不能变大，不能变小，不能被拉长，不能缩成一团又变回来。

动作（共 5 秒，一次完成，利落，不拖泥带水，只有这几步，不要多余的动作）：
0.0–0.6秒：站着，和首帧一样；
0.6–1.2秒：双腿一蹬跳起来，双手向上伸，同时抓住蓝色平台的上沿（平台比他高很多，他够到的是上沿的边角）；
1.2–1.5秒：双手挂在上沿，身体吊着，双脚轻轻悬着（不乱蹬）；
1.5–2.8秒：双臂用力把身体拉上去，一条腿勾上平台，身体翻上平台上沿，一个连贯的动作；
2.8–3.6秒：一条腿先站稳，另一条腿跟上，身体一次性站直（不爬行，不跪着停留，不弓着背，不拉伸，不站得比最终姿势更高），脚踩在平台上沿线上；
3.6–5.0秒：站直待机，和尾帧图里的姿势、大小、位置一样，之后基本静止，只有极轻微的呼吸。

整个过程中蓝色平台完全不动。没有爬行，没有弓背喘气，没有拉伸，没有擦汗。时长 5 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

## 更新（取消喘息）
弯腰扶膝喘息和直起身取消了：`tired_stop`、`tired_idle`、`tired_rise` 不再打包，从跑动松键就是直接站住（`idle_left`）。直起身这条（视频 1）不用再做。原因：喘息后的直起身怎么接都会和待机有一次变形 / 跳变。攀爬末尾仍然是 RIFE 变形到待机的临时做法，攀爬视频（视频 4）还是要重做。
