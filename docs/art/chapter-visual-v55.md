# 第一章连续画面复核 v55

2026-11-20。延续 v54 玩家活动空间焦点方案，依据项目美术 skill 与已有 LIMBO 视频研究。此次没有替换关卡布局、角色资源、物理参数或动画。

## 本轮修正

- 三棵悬崖树和绳索是独立可动节点，原先遗漏在玩法覆盖之外。补齐注册，并让后两棵树仍属于室外悬崖空间，避免过早套用矿洞焦点。树的线性 HDR 墨色由 `.004` 改为 `.00012`，不再在恢复清晰后显出灰木面。
- 地面、手持和抛出的独立石头进入同一覆盖层。去掉小石头扩大透明轮廓的做法，保留原外形与细抗锯齿。补齐实际木桥表面、矿洞可破墙体等独立对象；树、车、小物品用语义分组防止未来遗漏。
- 屏幕受光通道只补充空气，停止用亮度梯度给所有黑边描光，也不再给黑地面铺灰色高斯条带。角色材质接收方向性的弱宽面光和包裹光；保留体型、脸部与动画源图。石头不再通过假屏幕亮边表现受光。
- 胶片颗粒在近黑处渐隐，保留中间调颗粒；降低整章的投影闪烁和竖向划痕。黑色不再被线性 HDR 加法噪声抬成爬动的灰点。背景扩散、亮部晕光与前景失焦仍保留。
- 新增 `chapter_camera_framing.gd`：井架与双车区缓慢放宽至 0.90，逃离通道至 0.96；出矿洞前恢复。森林、悬崖和 C 区维持原倍率，常规跳跃不改变目标倍率。相机中心和事件优先级仍由原控制器掌管。按渲染时间积分，避免高频物理帧使镜头变慢；死亡光圈同步实际画布变换。

## 连续画面检查与边界

`chapter_visual_v55_review.gd` 沿七段路线记录每个采样渲染帧，24 fps 的脚本时间、共 1,656 帧；调整前后各采集一组，原生渲染 1280×720。每帧保留 640×360 线性 HDR 数据，约每秒另留一张原生 HDR 截图。采样路径直接设定角色位置，部分穿越不是合法玩法动作，不能把画面中的飞行或穿越解释成游戏 bug。

`scripts/tools/analyse_chapter_visual_review.py <目录>` 对全部帧计算相邻变化、明度和暗部比例，并输出逐帧视频、分段拼图、差异候选。人工查看七段拼图与候选画面，并在原尺寸检查树干、石头、角色、井架和实跑矿车截图；**没有声称人工逐帧看完全部图像，或已经从头到尾无辅助通关**。最大帧差主要在井架升降取景与前景大树掠过时；数值只能定位候选，不能自动证明有／没有加载问题。
