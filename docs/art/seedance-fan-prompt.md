# Seedance：芭蕉扇（轻但大的物件）— 拾取、双手蓄力挥动、放下（10 秒，无实物）

三种物件的区别：
- 小物件（石头等）：单手，轻，视频 A。
- 大而重的物件（木头）：双手抱着，吃力，上身后仰，视频 B。
- 芭蕉扇（轻但大）：拾取毫不费力，平时右手拿着（与视频 A 的单手持物姿势衔接，跑和跳直接用 A 的片段），挥动时左手加入变成双手握，身体向镜头转过来、蓄力、转回朝左全身发力挥出大弧线，再回到右手单手持物。

- 首帧：`artifacts/character-concepts/hood/rest_left_green_small.png`；10 秒、1:1、固定机位、最高分辨率、24 帧每秒。
- 抽帧后：`fan_pickup`（放下是它的倒放，或用视频里的放下片段）、`fan_swing_1`、`fan_swing_2`、`fan_putdown`；量出每帧双手握杆的位置和杆的方向，扇叶由游戏画在杆上。

## 提示词

```
【最重要的规则】
整个视频里只有一个角色。画面里没有任何其他物体：没有扇子、叶子、棍子、杆子、石头、木头、绳子、墙、道具或任何东西，也没有地面线、阴影、灰尘。角色是在做哑剧：他拿着的东西是完全看不见的，他的手只是握成半握拳的形状，像握着一根看不见的细杆，手里和手的周围是空的，手臂挥动的轨迹里也不会出现任何形状。不要画出、不要生成、不要暗示任何物体。

【画面与视角】
严格使用参考图中的同一个角色：黑色纯剪影、尖兜帽的小男孩，帽尖向后弯，只有一只橙色发光的眼睛（身体转向镜头时仍然只有这一只眼睛），披风短袍和短裤，赤脚，无任何其他颜色、细节或描边。
这是 2D 横版平台游戏的侧视镜头：正交，镜头与角色胸口等高，完全水平，没有俯视或仰视，没有透视变化。
背景为平整的纯绿色（#00FF00）绿幕。
镜头完全固定：不推拉、不摇移、不抖动、不缩放。
角色的双脚始终站在原地（只有很小的重心调整），位置在画面里基本不变，整个人始终完整在画面内，大小始终与首帧一致。
站立时脚底始终回到首帧脚底所在的同一条水平高度（画面约 79% 处）。
二维动画质感，动作流畅自然、有重量感，兜帽尖、衣摆有惯性跟随。动作速度均匀，不要慢动作，不要重复帧，不要卡顿。时长 10 秒，24 帧每秒。

【时间轴】
0.0–0.4秒：保持首帧的站立姿势，侧身朝向画面左侧，脚并拢，轻微呼吸。
0.4–1.6秒：拾取：弯膝，上身前倾，双手一起伸向身前地面，握住一根看不见的细杆，轻轻一提就拎起来，毫不费力，像拿起一个又大又轻的东西，身体几乎不受重量影响；站直时左手松开，只剩靠近镜头的右手握着，右手停在腰前，手指弯成半握拳，左手自然下垂。
1.6–2.2秒：持物待机：右手在腰前保持半握拳，左手自然下垂，轻微呼吸。
2.2–4.4秒：第一次挥动：左手伸出来和右手一起握住那根看不见的细杆，双手握在一起；上身和头向镜头转过来，从侧身慢慢转到近乎正面朝向镜头，只有一只橙色发光的眼睛；双手握着细杆向身体右后方举过肩膀，重心移到后腿，身体向后拧紧蓄力（约 0.7 秒）；然后全身发力，腰、肩、手臂一起转回朝向画面左侧，双臂伸直，向前下方挥出一个很大的弧线（约 0.3 秒），兜帽尖甩动；挥完顺势向前，然后双手收回，身体转回正侧面朝左，左手松开自然下垂，右手回到腰前半握拳（约 0.8 秒）。
4.4–5.0秒：持物待机：右手在腰前半握拳。
5.0–7.0秒：第二次挥动：同样的动作再做一次，节奏更快一点：转向镜头蓄力、转回朝左大弧线挥出、收回到右手持物。
7.0–7.6秒：持物待机。
7.6–8.8秒：放下：弯膝，上身前倾，右手把看不见的细杆轻轻放在身前地面，手指松开，手里是空的，然后站直。
8.8–10.0秒：站稳，回到与首帧完全一样的站立姿势：侧身朝左，双脚并拢，双臂自然下垂，轻微呼吸，静止。

【禁止】
任何扇子、叶子、棍子、杆子、绳子、石头或其他物体（任何颜色、任何大小、任何位置），包括手臂挥动形成的任何附加形状；双眼（只能有一只眼睛）；整体转身离开镜头或背对镜头；改变站立位置；镜头运动、角色大小变化、角色变形或颜色变化、出画、文字、水印、慢动作、动作停顿卡住。
```
