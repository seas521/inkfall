# V88 — 出口远景、回推矿车与对岸复活

## 当前要求

用户要求处理矿洞出口到谷底森林的远景衔接、悬空树根、回推矿车卡住，以及成功抵达后掉落却回到矿洞关卡的问题；随后明确要求取消谷底森林新增光影，重新考虑方案。

## 已完成的行为

- 旧矿洞树林背景和旧山体底板在实际洞口内逐渐退出。出口、出口预览、坐标交接后的谷底森林沿用同一套基础远景投影，不再把两套不同树林叠到落地平台后面；山体底板也不会在树林后露出水平矩形边缘。
- 仅远景树的完整根盘隐入同层远雾，保留树干上部和分层视差；近处树根仍由真实岸体遮挡，未裁剪玩家层树木。
- 谷底森林新增的世界光束、角色／物件受光、前侧散射及水面附加接光已停用。河岸日光缓存不再创建，恢复基础森林投影与原有水面材质。基础背景图片自身的明暗保留，上方森林、矿灯、全章镜头柔和度不改。
- 落地矿车不再沿无限的固定高度轨道悬空移动。回推越过岸边，车会脱手、先由剩余车轴支撑着倾斜，再坠落；安全站在岸上的玩家不会被强制拖下去，可以立即反向走开。即便旧状态把零速度矿车留在岸边，也会完成倾落而非永久悬挂。
- 真正成功抵达对岸后保存独立的抵达记录。之后在出口掉落，会在对岸安全地面复活，并恢复落地矿车，避免重新做矿洞接力；返程不丢失这一记录。玩家尚未成功跨越时仍使用原有接力检查点，不以无人矿车到岸给玩家开通传送捷径。
