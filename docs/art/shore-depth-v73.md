# 树在岸后与水岸融合 V73

用户要求岸上大树位于玩家后方，树根不得贴在地面表面；并指出水岸仍有明显拼接感。本轮保留V72透射为主的处理，修改两项空间关系。

岸树移至z=-4，完整不透明岸体z=-2在其前，角色仍在z=5。根部由真实岸体遮挡，不裁角色、不切树图、不改碰撞。左右两岸树使用同一规则。

水下岸体失焦随深度增加；其局部对比逐渐融入朝水域一侧采样的水色，不以固定灰值替代。岸面高度场梯度用于确定朝向开放水域的采样方向，浅层保留黑岸，深处逐渐退去硬边。接触反光适当展宽并减低峰值，让贴岸与船边属于同一水位。干岸仍保持完整，芦苇与角色素材不变。

原生1280×720覆盖树下、两岸、入水点、船上静止/运动及登岸后大树。28项局部状态、图像与层级检查通过，Godot日志无解析、Shader及图像越界错误；连续推进45帧视野。截图和日志在artifacts/shore-depth-v73。非整章人工通关，不据此宣称已达到参考作品效果。
