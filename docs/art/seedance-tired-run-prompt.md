# 疲于奔命的跑步：Seedance 动作提示词

现在的跑步循环（`run_l1`）是一条干净利落的冲刺：步子轻、摆臂大、躯干挺直，看上去像在跑酷。游戏里已经把速度降到 88%、腿放慢、上身加了前倾，但这些都只是在原动作上做变换，改不了动作本身。要"疲于奔命"的感觉，需要重新生成一条。

## 要什么
一个已经跑了很久、快要力竭的孩子：上身明显前倾、头低着、肩膀塌下去；步幅短而沉，脚抬得不高、落地发重；手臂不再大幅摆动，而是松垂着小幅甩动，偶尔一只手捂向侧腰；整个身子随步伐上下沉浮，每一步都像是咬着牙迈出去的。节奏不是慢，是"赶着往前、但撑不住"。

## 提示词（可直接贴）

【最重要的规则】整个视频里只有一个角色。画面里没有任何其他物体：没有地面物件、没有石头、没有水、没有树、没有烟尘，也没有任何道具。

纯绿色背景，固定侧面机位（横版游戏视角），镜头不动，不推拉，不摇晃。角色全身入镜，面朝画面左侧，在原地"跑步机式"跑动：身体在画面中的水平位置基本不变，只有腿和手臂在动，一条隐形的地面线固定不动。

角色：头戴尖兜帽的小男孩，黑色剪影风格，斗篷下摆随步伐沉重地晃动。

动作：连续跑动的循环动作，约 6 步（3 个完整循环）。他已经精疲力竭，仍在拼命往前跑：
- 上身前倾约 25 到 30 度，头垂得很低，下巴几乎贴着胸口，肩膀往前塌；
- 步幅很短，膝盖抬得很低，脚落地时整个身体往下一沉，每一步都有明显的重量感；
- 手臂几乎不用力，松松垂在身前，随步伐小幅度甩动，肘部弯曲不超过 90 度；
- 呼吸很重，胸口和肩膀随呼吸起伏，节奏比脚步慢一拍；
- 始终向前赶，没有停顿，没有回头。
动作首尾衔接，可以无缝循环。

时长 10 秒，24 帧，镜头固定，不要出现任何文字、字幕、特效。

## 接进游戏时要做的
抽帧、插帧到 60 fps，找一个步态循环（左右脚各一步）。再按"跑步一圈 ≈ 0.45 秒"重新定时（`run_l1` 的做法），换掉 `run_l1`，同时补一条带物的版本（`small_run_l1`，拿石头或扇子时用）。
