# 清透水域及干岸范围 V71

用户指出水层伸到岸边大树下，且水体整体发灰。保留V70本地源文件后修改三处：

- 岸体取消自身的全幅深度alpha消隐，干岸保持完整黑色。水下覆盖只在实际河口的两侧作有限宽度软过渡；远水边界仍依赖原岸体轮廓，避免固定矩形截断。
- 降低开放水面的灰色底值、大片反光及噪声幅度，保留较弱的环境倒影和局部波光。没有全屏曝光或统一压黑操作。
- 浅水岸体透射提高、失焦减弱，深部渐进衰减；保持黑岸透过水可辨，而非由灰色雾层替代。

原生1280×720复核干岸船架/树根、左岸、入水点、水中、宽镜头及右岸；22项局部检查通过。V71的树根地基像素对比随后发现采样点越界，不能作为通过证据；V72已改为画面内采样并先验证坐标有效。V71干岸关系以原生截图复核为依据。连续推进视野45帧，日志无解析及Shader错误。此为局部画面及状态验证，不代替整章通关。
