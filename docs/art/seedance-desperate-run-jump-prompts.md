# 奋力逃命：奔跑、笨拙跳跃、攀爬的 Seedance 提示词

目标：不要"跑酷"，要一个又累又被追着的孩子。奔跑有疲惫和紧迫，跳跃低而笨拙（对标《Limbo》：约一个身高，落地发沉），高处的台阶和箱子靠攀爬上去，不是一个大跳。这份取代 `seedance-tired-run-prompt.md`。

三条各 5 秒，共 15 秒。每条提示词都是完整的，直接粘贴，不需要拼接（见对话中的完整文本；这里只记录设计）。

## 通用设置
- 首帧和参考图：`artifacts/character-concepts/hood/rest_left_green_small.png`。
- 5 秒，1:1，镜头锁定，最高分辨率，24 fps。
- 抽帧：`scripts/tools/seedance_frames.py VIDEO --name <clip> --start N --end M --scale 0.528 --root-x 456.8 --ground-y 759`，插帧 `rife_upsample.py`，打包 `package_hood_actor.py`。

## 1. 疲惫奔逃（5 秒）
| 时间 | 内容 |
| --- | --- |
| 0.0–0.6s | 站着大口喘气，上身前倾 |
| 0.6–1.2s | 向前猛地一栽起跑，踉跄两步 |
| 1.2–3.8s | 疲惫奔跑循环，至少 8 步，首尾可循环 |
| 3.8–4.5s | 踉跄刹停，身体前栽，双手撑膝 |
| 4.5–5.0s | 弯腰喘气，保持不动 |

接进游戏：`run_tired`（替换 `run_l1`）、`start_tired`、`stop_tired`、`idle_tired`（取最后一秒做循环，跑 3 秒以上再停下才用）。带物版本稍后补。回头瞥一眼的素材先删掉了，以后需要再单独生成。

## 2. 笨拙跳跃（5 秒）
| 时间 | 内容 |
| --- | --- |
| 0.0–0.4s | 站立 |
| 0.4–1.8s | 原地跳一次（深蹲、低跳、乱挥手臂、重落地、膝盖一软） |
| 1.8–2.3s | 踉跄起跑 |
| 2.3–3.0s | 疲惫奔跑 |
| 3.0–4.4s | 边跑边跳一次，落地沉重，踉跄两三步 |
| 4.4–5.0s | 刹停站稳 |

接进游戏：`jump_stand`、`jump_run`（各切成起跳蹲 / 上升 / 顶点 / 下落 / 落地缓冲）。数值配套：`JUMP_SPEED` −590 改约 −430（高点约 60 px），落地后 0.15 秒速度减半，不加起跳输入延迟；依赖现有跳高的台阶逐个核对。

## 3. 攀爬（5 秒，先放着）
| 时间 | 内容 |
| --- | --- |
| 0.0–0.5s | 站立喘气 |
| 0.5–1.1s | 跳起扒住看不见的边沿 |
| 1.1–2.1s | 悬挂，双脚乱蹬 |
| 2.1–3.2s | 撑起，一条腿勾上，翻上去 |
| 3.2–4.2s | 跪着喘气，站起来 |
| 4.2–5.0s | 站稳喘气 |

接进游戏：追踪每帧双手位置，边沿跟着手走；位移由动作里记录的整体位移带着走；不同高度的台阶要么缩放垂直位移，要么再生成更高的一条。攀爬机制（检测边沿、锁定输入、套用位移，A/B 区自写碰撞和 C 区物理引擎碰撞两套都要接）等素材到了再做。

## 顺序
先生成第 1 条，再第 2 条，确认后再第 3 条。
