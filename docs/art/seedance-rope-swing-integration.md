# 崖壁粗绳攀爬与摆荡 · 2026-11-13

范围：绳梯下方第一棵右侧崖壁树 → 沿绳下降 → 摆向左侧脆弱树枝 → 跳回右树 → 矿洞门口。矿洞内部和矿车仍未开放。

## 素材与动作

用户提供三个原生约 24 fps 的 Seedance 视频：7181（摆荡，241 帧）、6836（垂直抓绳和下爬，121 帧）、9398（上爬，121 帧）。工具分别为 `scripts/tools/build_rope_swing_clip.py`、`build_rope_climb_clip.py`、`build_rope_climb_up_clip.py`。使用 `-fps_mode passthrough` 提取原生帧，没有按容器标称帧率重复抽帧。

上爬原片朝右，打包时镜像统一为朝左。上下爬共用固定源图缩放 0.5234375；上爬悬挂姿势不能重新按站立高度归一化。绿幕与蓝色辅助绳被移除，身体压黑，眼睛沿用统一追踪光点。各帧围绕测得的手部根点裁剪，不按裁剪框重新居中或缩放。

运行时使用独立上爬片段，未倒放下爬。W 上爬、S 下爬；松键保留当前抓握高度与姿态。角色可返回最初抓绳高度。空格起跳抓绳，再按空格松手。所有抓握高度均可用左右键助摆；上部受实际地形碰撞约束，不再以深度禁用操作。

## 绳索模型

总模拟长度 368 世界单位，手部材料坐标为 110–340，绳尾至少保留 28。40 段固定材料节点组成整根绳，抓握点沿同一根绳移动，不新增或删除绳尾。

这是游戏使用的二维降阶模型：受力上段按变长度摆近似，重力角加速度随 `g / grip` 变化；改变抓握半径时按半径平方比例调整角速度，以近似保留角动量。所有高度使用同一助摆规则；角色运动以实际碰撞扫掠约束，碰到岩壁会损失摆动速度，而不是直接关闭上段输入。

绳体以细分时间步积分惯性与重力，距离约束维持长度。抓握位置位于节点之间时使用插值约束，避免跨节点跳动。受力上段趋向拉紧，自由绳尾保留惯性和弯曲；松手后只固定顶部绳结，整根绳继续回摆并受阻尼影响逐渐垂下。轻微环境风维持静止时的活动。未抓握时检测玩家经过绳身的扫掠接触，将运动传入自由节点，跳过绳子会产生扰动。这里并非完整三维绳索或绳索与场景的通用碰撞模拟。

## 布局与验证

第一棵树到左侧厚枝的落差约 300 世界单位；右侧下方树相对初版向右移 65（上一轮位置向左收回 60，增加起跳容错），并整体降低后续树与矿洞入口。入口不再位于绳尾正下方。保留统一角色跳跃及致命落差参数，测试需要实际完成左右交错路线。左树仍为延时断裂落点，下方右树的厚干稳定。

左右树的细枝簇单独拆层，下降碰到时断落、散出木屑，不承担角色站立。承重扫描要求连续木质厚度；厚干与根部切层保留遮盖余量，避免转动露出锯齿状白缝。

当前回归入口：`scripts/demos/c_zone_debug/cliff_rope_climb_smoke.gd`。覆盖垂直起跳抓绳、下降、松键悬停、上爬返回上限、下降下限、摆荡松手、左右树与矿洞落点、复位、普通跳跃不可绕过、较长受力段重力摆动响应更慢。新增绳尾直接松手/向右跳无法安全抵达下方右树或矿洞、上段助摆、经过自由绳产生扰动、细枝折落与复位测试；摆向对岸必须存在真正的向外运动松手窗口。Metal 模式保存 `artifacts/rope-swing/` 下的实际画面，包括 `07-down.png`、`08-up.png`、`09-bottom.png`。

原有矿车测试不适用于当前止步矿洞门口的范围。原始帧、接触表、打包预览位于 `artifacts/rope-climb/` 和 `artifacts/rope-climb-up/`。

## 脆弱落点的预告

左侧倒数第二个落点预先带有贯入木质的开放撕裂和下缘缺口，留下薄层纤维连接。裂口显示真实背景，不使用发光描边。受压时裂口逐步加深，转动支点对齐剩余纤维，末段连同细枝脱落。最后一棵树向左收回 60；回归改为距枝端 28 起跳，并要求落到对面端点内侧至少 12，避免只测极限跳跃。`cliff_branch_break_capture.gd` 验证受压前、受压、掉落与复位；完整路线回归通过。
