# Seedance：D 角色跳跃主片（10 秒，一次生成）

- 首帧和参考图：`artifacts/character-concepts/hood/rest_left_green_small.png`（纯绿幕，朝左站立的静止姿势，角色高约画面 40%，脚底在画面 79% 处，头顶留出约一个身高的空间给跳跃）。
- 设置：10 秒，1:1，固定机位（有镜头锁定就打开），最高分辨率。
- 要求角色在画面里水平位置不动（像跑步机上），只有跳起时垂直方向移动；抽帧后位移由游戏代码控制。
- 抽帧：`scripts/tools/seedance_frames.py VIDEO --name <clip> --start N --end M --scale 0.2736 --root-x 466.1 --ground-y 833`

## 时间轴

| 时间 | 内容 |
| --- | --- |
| 0.0–0.5s | 站立静止，轻微呼吸，脚并拢（与首帧一致） |
| 0.5–1.2s | 原地跳：下蹲蓄力（膝盖弯曲、身体下沉、手臂后摆） |
| 1.2–2.0s | 蹬地起跳，上升，手臂前摆，到达顶点 |
| 2.0–2.5s | 下落，兜帽尖和衣摆向上飘 |
| 2.5–3.1s | 落地缓冲：深蹲压低，兜帽尖下沉再回弹 |
| 3.1–4.3s | 起身，回到双脚并拢的站立姿势，静止 |
| 4.3–5.0s | 向左起跑，原地迈两三步 |
| 5.0–5.6s | 向左匀速奔跑 |
| 5.6–6.4s | 第一次跑动中起跳（蹬地、腾空、双腿一前一后跨开） |
| 6.4–6.9s | 落地缓冲，不停步，继续奔跑 |
| 6.9–7.6s | 向左奔跑 |
| 7.6–8.4s | 第二次跑动中起跳（比第一次略高，手臂更用力） |
| 8.4–9.0s | 落地缓冲，步子变小，减速 |
| 9.0–10.0s | 停稳，回到脚并拢的站立姿势，静止 |

## 抽帧参数提醒
首帧角色高约 380px（之前的视频约 732px），所以抽帧时用 `--scale 0.528`（0.2736×732/380），`--ground-y 760`，`--root-x` 用首帧的脚底中心，需要抽帧时再量。
