# 水面与透射恢复 V72

用户指出V71远近水没有区别、水平面无法辨认，且不及早期水域清透。对照artifacts/river-open-v48/before/river_art.gd的真实实现及V52原生河面截图，本轮只恢复早期透射主导的光学关系，不回滚后续关卡、岸体与近景布局。

水面接触位重新对齐真实575水位和现有波场；远处水面只后退约29世界单位，取消之前从495开始的高位灰墙。接触处为柔和窄幅反射，未画常亮白描边。

近水主要透过原画，轻微折射，并保留较高岸体透射；去除以低亮水色替代整片水下的做法。远水使用更柔和反射，近处保留入水岸体与船体接触。入水岸体仍可渐进柔化，水域不会延伸至树下；现有芦苇和水沫保留。

原生1280×720复核树下、左右岸、入水点、静止和运动船体，并连续推进45帧视野。23项局部状态及图像检查通过，Godot日志没有解析、Shader或图像越界错误。

修正V71图像检测中先前越界的采样点，先验证取样坐标位于截图内再比较水层开关：该对比确认树下干岸未被水染色。旧报告已注明此检测缺陷，不能把旧检测的PASS当有效证据。
