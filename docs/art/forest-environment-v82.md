# V82 森林融合强度对照

在 V81 基础上只提高既有共享光场的响应，不改变光路、焦点、形体、镜头、草丛布局或玩法。

- 新增 `fusion_gain`，默认 1.85，上一版为 1.0。人物、草叶和道具在同一亮隙内增强受光。
- 空气散射提高到约上一版的 1.55 倍，仍只使用既有开口与明亮空气。
- 土层增益逐渐回到 1.0，不随人物增益变成浅灰条带；脚边接触约束保持。
- 不增加全屏模糊、位移、玻璃折射或重影。

同机位对照与原生检查在 `artifacts/forest-environment-v82/review/`。11 项检查通过，覆盖形体／根点不变和矿洞、C 区不受影响。参数变化沿用 V81 的连续行走验证路径，没有改动控制器。

V81 两个涉及文件的完整未提交版本保存在 `artifacts/forest-environment-v82/rollback/`；V79 完整基准另行保留。未提交或推送 Git。
