# 双路吊运站 · Polyfork 第一批试用

先成立关卡和机关，再为机关选择合适的美术素材。素材不决定路线或谜题。

## 美术意图

峡谷中的废弃吊运站：承重门架和绞架形成结构地标，沿用原有远谷、雾光、黑色地形和前景层次。GLB 只提供轮廓及机械转轴，统一为无光照黑色材质与轻微软边，不展示彩色低模或 PBR 质感。

接入 Mine Cart、Timber Shaft Frame、Mine Headframe。矿车替换上层推车与下层配重车，原生车轮按实际推拉距离转动；两座井架替换原滑轮立柱，绳索连接实际转轴与原吊篮。隐藏素材自带吊桶和绳索，避免多出无作用的容器。

Cliff Perch Ledge 与 Ruined Lair Wall 在投影试验中产生硬直角和路线遮挡，未接入。源文件与授权记录保留供后续评估。

## 实现边界

未修改玩法控制器、碰撞布局、机关行程、关卡难度、镜头和角色动作。上层推车—悬板—跷跷板与下层配重—吊篮—阻挡木块两条路线保持原有逻辑。森林、悬梯、目的地木屋与 C 区保持原有素材。

采用透明正交 SubViewport 生成世界空间剪影，仅在机关状态改变且站区可见时重绘；角色仍在独立且更靠前的绘制层。

## 第二版：减少上下路线重叠

撤掉出口处跨越上层台阶的大井架，改为固定在上层岩台边缘的小滑轮；配重端井架缩小并移至台边，远离推车。下层缆绳单独在地形后方绘制，连接吊篮上方悬挂点，岩石遮挡关系正确。删去重复的中景吊臂，保留峡谷与空气层作为背景。未修改任何碰撞、路线或机关运动。修订截图保存在 `artifacts/polyfork-station/reduced/`。
