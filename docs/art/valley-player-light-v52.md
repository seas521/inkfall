# 谷底森林玩家层光照 v52

同轮景深调整见 `docs/art/valley-player-focus-v53.md`，原生图层遮罩属于景深模块。

修改前代码点：`4cebe3ca`（v51 角色单独受光）。当前调整以 LIMBO 森林里的黑色角色、亮雾和地表明暗关系为参考，保持 v43 柔化和原有远景构图。

- 同一投影光场驱动人物、局部空气和地表。近处光斑用固定世界坐标的林冠间隙打散，缓慢变化；角色走动与镜头移动不会产生随机闪烁。
- 人物降低整体灰度，只保留很少的迎光帽沿、肩背亮面，背光侧继续深黑。草地和道具的迎光边缘也受到这束光影响。
- 薄雾与稀疏微尘只在亮区可见，遇到深黑剪影显著减弱，避免人物被整片灰雾覆盖。地表接触光仅落在现有关卡轮廓附近；通过屏幕内剪影的短距离可见性采样，减弱人物、道具后方的光斑。
- 地形轮廓一次采样为小尺寸浮点纹理，复用已有地形数据。一个接收平面，不新增渲染视口、物理灯光或每帧碰撞射线。全局电影柔化继续作用于结果。
- 仅实时 C 区启用；矿洞预览、上方森林和菜单关闭。河水明确排除这次叠加，保持恢复后的水体效果；空隙不会生成发光地面。

验证：`scripts/demos/c_zone_debug/valley_player_light_v52_review.gd` 在固定相机下对比光区/阴影区开关及左右朝向，并检查随镜头变化的河岸、坡面、退出 C 区的关闭、河水排除和悬空处无光斑。使用 `INKFALL_LIGHT_1080=1` 覆盖 1920×1080，默认 1280×720。原生 HDR 截图只存在本机 `artifacts/valley-player-light-v52/`。

参考：[Playdead 森林截图](https://playdead.com/css/img/limbo/screenshots/LIMBO_05.jpg)、[HOTEL 实机片段](https://www.youtube.com/watch?v=XsHaO_bRP74&t=177s)。这里的接收与遮挡是当前 2D 屏幕空间近似。
