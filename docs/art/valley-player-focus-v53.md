# C 区玩家附近的分层景深 v53

本轮调整前代码点：`4cebe3ca`。v52 光照与 v53 景深作为这轮 C 区试作一并保存，保留上方森林、矿洞、水体和 v43 的既有处理。

玩家当前所在区域的角色、近处道具和脚下草地相对清楚，仍有轻微软边；距离增加后连续恢复原有柔化。远景和镜头前遮挡保留自身景深，不随角色附近的清晰区域一起变锐。原有曝光、颗粒与受光风格保留。

实际图层覆盖由 640×360 的透明遮罩视口取得：复用现有 World2D 和已经生成的角色/场景纹理，只渲染明确标记的交互层。不开第二套场景、物理或动画。最终电影通道仅在真实图层遮罩与角色周围的平滑范围交集内减弱光学扩散，避免把背景上的暗树误判为人物，也避免出现一圈整体变清楚的圆形窗口。主体原始材质柔化保持不变。

C 区启用时更新遮罩，其他区域停止更新并关闭作用。关卡隐藏或退出时电影材质清理对应状态，菜单不保留景深效果。光照部分沿用 v52 的共享投影、光斑、微尘、薄雾及剪影遮挡。

验证脚本：`scripts/demos/c_zone_debug/valley_player_focus_v53_review.gd`，包含阴影/光区、左右朝向、河岸、坡面、真实人物在遮罩内且背景在遮罩外、河水排除、悬空处无发光地面和退出 C 区清理。默认 720p，`INKFALL_LIGHT_1080=1` 验证 1080p。本机截图目录为 `artifacts/valley-player-focus-v53/`。

本轮回滚时恢复 `4cebe3ca` 对应的角色、river_art、光场、电影通道与电影宿主脚本，断开本轮新增的 light/focus 宿主，不影响之前确认的去树、原水体和白色火焰。
