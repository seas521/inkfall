# 森林岩洞：斜向洞口与连续通道

2026-11-11。本版空间基准为用户批准的 `exec-08773986-ba00-4527-b399-e0a30e4070e8.png`：参考《小小梦魇Ⅱ》森林洞口的组织方式，入口嵌在坡体中，斜向朝镜头敞开。横版移动不限制洞口必须纯侧视。旧独立石拱、旧山体全景、尖形出口均停用。

## 当前版本

用户最终取消木板。木板实体、碰撞、交互、动作锁和绘制均已移除；角色可直接接近洞口。

- 入口：`assets/art/rock-crevice/oblique-entrance-v1.png`。
- 出口：`assets/art/rock-crevice/oblique-exit-v1.png`，同一种厚岩唇、根系和连续坡体。
- 内部低通道：`inner-exit-v1.png`，外侧出口由独立完整坡体覆盖。
- 运行时：`rock_crevice_art.gd`、`cave_oblique_plate.gdshader`。

纹理偏重的v2只保留为制作过程稿，不用于当前渲染。当前岩面做低对比与局部低通，压制细纹，保留大形和非常弱的环境受光转折。洞口暗部严格按原图不规则轮廓标注，不再使用圆形亮度遮罩，不在黑色岩体上画一个发亮圆洞。地面亮带已经收低。

完整底层位于角色与蜘蛛后方；近侧岩唇在角色前方单独绘制，边界随原图岩唇倾斜：进入时脚部先被遮挡、随后身体进入岩体背后的低通道；出口反向显露身体。禁止角色完整地盖在洞口近侧实心岩唇上。前景遮挡不承担挡路碰撞；真实通行高度由同一布局的岩顶碰撞限制。源图地面基线与既有地形对应，角色不缩放、不切镜头。

## 移动与通道感

- 入口外38px开始自动弯腰，先完成进入低姿动作，再走到低矮岩唇下。
- 中段净高67px，低于站立视觉高度。使用既有Seedance低姿进入、待机、步行、起身动作；低姿行走速度60。
- 近侧厚岩体短暂遮挡，内部有不透景的暗灰后壁和黑色低顶。离开实际出口低顶后才起身，不在洞里提前站起。
- 雨声随入洞深度平滑降低9dB，离洞恢复。细小碎屑落到真实地面后扬尘；落石只出现在内部岩顶下，不在已开阔的出口凭空生成。
- 角色仍为全局0.90比例与单只橙色眼睛。Space跳跃、S空旷处低姿、绳梯W/S控制沿用原有规则。

蜘蛛身体停在入口外300px；腿端不越过入口岩唇边界；攻击仍受真实距离及岩体射线遮挡约束。通过后蜘蛛原地挣扎，再面向玩家倒退离开。悬崖绝对位置-3500、远处木屋、墓标、乌鸦、自动行走、绳梯和断桥保留。

## 整片森林远景与水潭

`assets/art/c_zone_debug/forest/forest-depth-v1.png` 覆盖从起身、倒木、食人花、水潭、蜘蛛追逐直到洞口的整段森林。`misty_forest.gd` 与 `forest_depth_plate.gdshader` 使用预加载图像、缓慢雾光变化和0.18视差。旧远、中景粗树图层已完整移除，不再低强度叠加；近景遮挡独立保留。树木在岩洞遮挡区逐步收束，出口显露原悬崖远山，不覆盖远处目的地木屋。整体曝光已降低。

新远景让旧水体的浅灰填色与空气雾混合。本版去掉浅灰常量填色，改为随水深吸收的折射画面；表层保留更集中的反射、局部波光和脚步波纹，水下腿部仍可见。水体深度、岸线和移动速度不改。

草皮继续复用全段缓存、地形贴合和岸边24px渐隐。洞内草根带单独收薄，不影响水岸修复。
