# 矿洞背景接缝与兔子取物诊断 V77

背景竖缝来自V76实体岩缘裁边影响到远处壁画，加上多张非前景底图没有统一入口过渡。岩缘覆盖现在只在地面附近渐进生效，不再从顶部沿整张背景切下去。背景底图共用200世界单位左右的入口羽化；前景只柔化最外侧约67单位、且在地面前恢复完全不透明，指示牌、木架和实体岩体保留黑色。未改变机关、碰撞和灯源。

原生1280×720复核井架交界的近处取景、断轨全景，以及上轮修复的矿洞出口预览/交接/返程；22项检查通过，日志无解析和Shader错误。美术仍以实际画面为准。

兔子单独实机诊断：现有素材为small_pickup蹲地拾取。动作约0.433秒、源clip第25帧时已脱绳，手离原抓取点约89.4世界像素。控制器之后用pickup_from.lerp(hand)把兔子移动到手边，造成物体主动飞来。现有fan_pickup同样来自地面；抓边/climb片段不能充当双脚落地的向上取物而不破坏身体姿势。

建议补一段5秒无实物站立向前上方取物，再按真实接触帧交接、脱绳、跟随和垂坠。兔子角色动作本轮仅诊断，没有以肢体拉伸、裁脸、自动走位或强行插值替换来掩盖；等待新素材后接入。完整生成词在artifacts/mine-seam-rabbit-v77/seedance-hanging-pickup-5s.txt。诊断截图与逐帧hand/bait数据同目录归档。
