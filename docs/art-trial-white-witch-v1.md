# 1-01 美术试玩版 · 2026-09-07

本轮只更换绘制层，保留现有 B/C 台阶位置、角色碰撞、跳跃、危险时序和投掷计算。

## 已接入

- B 区：井壁与井内远景分别滚动；台阶使用独立透明图片；火焰保持向上喷发并增加亮芯和局部光晕。
- C 区：背景连续镜像铺展并以 0.42 倍镜头位移滚动；台阶图片、水流细纹、气流雾团分别绘制。
- 白衣角色：独立动作图集，待机、四帧行走、起跳、下落、落地、拾取、持物、蓄力、释放。只有第一关使用新角色，其他关卡暂不替换。
- 角色使用原有 26×54 碰撞，视觉高约 67。每帧采用独立区域和脚底锚点；着地压低姿态不改变碰撞。
- 圣光独立绘制；角色着色器剔除生成素材的低透明背景残留，避免矩形光雾边界。

## 试玩方式

正常打开项目运行第一关（场景仍设置 debug_start_level=1），从井口进入 B，再下降到 C。Esc 返回已有关卡菜单。

重点观察：两侧落空缝、火焰安全边、角色脚底贴合、左右转向、起跳与落地姿态、F 拾物和长按 F 投掷。

## 已知第一版限制

- 行走只有四个关键帧，持物步态尚未单独绘制，动作精修未完成。
- 背景采用镜像拼接而非整关独一无二长卷，长距离行走可能辨认出重复结构。
- A 地表仍保留原简化环境；本轮主要验收 B/C 与角色。
- 未运行 Godot，没有宣称通过实机视觉或物理测试。
