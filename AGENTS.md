# Inkfall project guidance

For level/environment art, lighting, scene depth, character light integration,
or camera composition, read and use
[inkfall-cinematic-level-art](.cursor/skills/inkfall-cinematic-level-art/SKILL.md).
Its linked standards and timestamped LIMBO study hold the project's visual direction.
Apply character guidance for the current chapter; archived prototype designs do
not authorize replacing the current player or animation assets.

Runtime screenshots, reference-video extracts, and local rollback copies belong
under ignored `artifacts/`, outside game resources. Preserve existing uncommitted
changes when making a rollback point. User instructions take precedence over
project guidance.
